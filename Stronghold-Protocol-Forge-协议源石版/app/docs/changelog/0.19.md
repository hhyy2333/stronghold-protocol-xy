## 暂未发布

### 改：第16回合「木桩演练」到时间全体自爆 + 结算锁血（业主 2026-11-05）

- **需求**（业主 2026-11-05「第十六回合本质dps检测，能不能给这个木桩怪物加一个到时间自动爆炸。现在的问题是，第十六回合
  结束时会扣3点血，在协议等级加持后扣5滴，如果通过时最高血量不够就会扣血，并显示游戏失败」＋「把第16回合的时间加
  5秒钟，并且在最后5秒内所有怪物强制自杀且回合结束后玩家血量锁定不变」）：量输出的一回合不该在结束时罚玩家，更不该把
  打赢的最后一回合判负。
- **根因**（不是木桩本身）：这一回合走的是普通回合的**超时**结束 —— `server/sim/battle/lifecycle.js _timeout` 会把场上
  还活着的每个非首领敌人记成「漏怪」，而结算按**条数**扣 LP（`server/match/match/settle.js` 的 `counted`，与 `lpr` 无关）。
  60 s 一到，木桩（1 条）加上这一回合插进来的悬赏 / 协议源石敌人（各 1 条）一起算漏怪：3 条 = 3 点；协议等级 18 / 19 的
  `leakLp: 2` 再叠成 5 点。第16回合是最后一回合，LP 不够就当场淘汰、显示失败。
- **做法**（三层，缺一不可）：
  - **加时**：`rounds["16"].combatTimeLimit` 60 → **65**（`levelMaxPlayTime` 与 `waves.json custom_dummy.maxPlayTime` 同步），
    多出的 5 s 是「自爆窗口」。
  - **到时间自爆**：新增 `rounds["16"].enemySelfDestructAt: 60`（**real** 秒）→ `GameData.enemySelfDestructAt`（× 战斗倍速
    = 游戏秒 120）→ `waves.js buildNormalWave` → `combat.js _normalOpts` 的 `Battle opts.enemySelfDestructAt` →
    `sim/spec.js` 的 BattleSpec 同名字段（客户端、服务端真跑、复算读同一份）→ `battle/lifecycle.js _selfDestructEnemies`。
    那一刻场上**所有**敌人以 reason `selfdestruct` 被移除：**不记击杀**、**不付悬赏**、**不记漏怪**（完美作战不破），`die`
    事件照发（客户端照常播死亡动画）。木桩的锁血（`fatal` 钩子）不在这条路径上 —— 自爆是引擎的移除，不经过伤害结算。
    场上清空后战斗以 `cleared` 结束，量输出窗口仍是 60 s（DPS 读数与改动前同一把尺子）。
  - **结算锁血**：`settle.js` 在这一回合把 LP 损失锁成 0（与「背水一战」的锁血同一处判定），给**回合内更早漏掉**的敌人兜底；
    `stats.leaks` 照实记（面板不撒谎），只有 LP 那一笔是 0。
- **数据只在声明了这一格的回合上写它**：`tools/build-data.mjs addDummyRound` 只在 research 给了 `enemySelfDestructAt` 时
  写进 `rounds["16"]`；没有这个键 ⇒ `GameData.enemySelfDestructAt` 返回 null ⇒ Battle 与 spec 逐字节与从前相同。官方
  15 个回合与旧数据一个字节都不动。`audit.js`（`tools/matchrun.mjs --check`）的结算校验同步：第16回合期望 loss 0、
  不许在这一回合淘汰玩家。
- **测试**：`test/sim/dummy.test.js` 新增 3 条（到时间自爆是死亡而不是击杀 / 漏怪、没有这条规则时仍是旧的超时漏怪、
  自爆不付悬赏）；`test/match/dummyround.test.js` 更新数据 / 出怪 / 战场断言，新增 3 条（第16回合漏 3 只也不扣 LP 且
  仍是胜利、普通回合照旧扣、BattleSpec 往返带着这一格）；`test/helpers/battleHarness.js` 透传该选项。**golden 不移动**。
