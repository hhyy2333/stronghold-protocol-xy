### 修：【圣佑】狙击的「累计子弹量」不因发射清零（业主 2026-11-04）

- **报障**（业主 2026-11-04「源石协议圣佑的狙击伤害依然存在bug，没有正确计算伤害，并且造成伤害时间的间隔也不是3秒，
  如果敌人不在拉特兰干员攻击范围内甚至无狙击伤害」）：三条现象都是同一个根因。
- **根因**：卡面写「本场战斗**累计**统计【拉特兰】干员消耗的子弹量，每 3 秒对场上随机一名敌人进行一次狙击，造成
  **累计子弹量** ×325 的物理伤害」，实现却在每发狙击后把累计清零（2026-10-31 落地时写的「发射后清零」是实现自己
  补的 [ASSUMED]，业主原话与卡面都没有这一步）。于是：① 打出的伤害只算最近 3 秒的子弹量，不是本场累计；② 没有
  新子弹消耗时整段不发射，实际间隔不止 3 秒；③ 敌人不在拉特兰干员攻击范围内时干员不攻击 ⇒ 没有新子弹 ⇒ 完全没有
  狙击伤害。
- **修法**（`server/sim/content/hexcards/stone_kjerag_laterano.js` 的 `snipeOnce`）：累计**只增不清**。每 3 秒的脉冲
  按本场累计子弹量对**全场**随机一名活敌人狙击一次（目标选择与干员攻击范围无关）；场上没有活敌人时仍不发射、累计
  留着。返回句柄的 `pending`（「还没打出去的」）改名为 `ammoTotal`（本场累计子弹量）。
- **测试**：`test/sim/hex-stone-kjerag-laterano.test.js` 37/37。新增/改写四条把三条报障各自钉住：累计不因发射清零；
  没有新子弹也每 3 秒照打；新子弹进同一笔累计（4 → 8 颗，第三发按 8 × 325）；敌人不在干员攻击范围内也每 3 秒被
  狙击一次（目标在射程外、干员从未普通攻击过它）。
- **文档**：`docs/design/match.md` §29 与 `04-文档/协议源石-死亡之舞与四张卡调整-设计稿-20261031.md` §3.2.2。

### 修：【绿洲】开技能获得的护盾不叠加（业主 2026-11-05）

- **现象**（业主 2026-11-05「修复一下源石协议绿洲萨尔贡干员开启技能后获取的护盾无法叠加的问题」）：【绿洲】
  `hex_sargon_oasis` 每次开技能给 100% 攻击力的护盾，但连开两次技能盾不涨 —— 第二次的盾只要不比剩余的多就一点都不加。
- **根因**：战斗半边（`server/sim/content/hexcards/stone_yan_sargon.js` `installSargonOasis`）把同名护盾 buff
  按 `Math.max(当前剩余, 新值)` 刷新（当时按 `[ASSUMED]` 写成「不无限叠加」），于是护盾永远只有「一次技能」那么厚。
- **修法**：改成**累加** `当前剩余 + 新值`。连开两次技能 = 200% 攻击力；被打掉一部分后再开技能也在剩余上继续加。
  「下一次攻击额外造成等同当前护盾值的法术伤害」口径不变 —— 按攻击那一刻的剩余护盾结算，所以累加后的那一份也进附伤。
  「一次技能一次附伤」的 pending 标记、`shieldPct` 参数、60/325 层里程碑、卡面文案都不动。
- **测试**：`test/sim/hex-stone-yan-sargon.test.js` 新增「绿洲: 再次开技能的护盾累加，附伤按累加后的护盾结算
  （业主 2026-11-05）」（一次 400 → 两次 800 → 掉 300 剩 500 → 再开 900 → 附伤 900）；换回旧写法时这条会红（已验证）。
  **golden 不移动**：协议源石战斗卡片不进官方内容的 golden 语料。
