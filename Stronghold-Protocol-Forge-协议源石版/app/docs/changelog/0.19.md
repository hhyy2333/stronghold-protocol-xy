## 暂未发布

### 修：特限模组空弦（ISW-A「空弦特限证章」）的回技力那半没生效（业主 2026-11-05）

- **现象**（业主 2026-11-05「特限模组空弦回技力部分没生效」）：【特限恢复】`hex_mode_modules` 下空弦装备 ISW-A
  「空弦特限证章」时，**特性**那一半（每有一名攻击回复干员在场，攻击距离 +1，最高 +3）生效，但 3 级**天赋**
  【兰登战术】追加的三句一句都没实现。
- **官方原文**（03 STAGE，BWIKI `空弦/模组3`；`data/moduleLevels.json` 的 `uniequip_004_archet` talentChanges）：
  「在场时所有【狙击】干员的攻击回复技能每2.5秒回复1点技力；在集成战略中，所有干员的攻击回复技能都享受该效果且能被
  空弦的攻击回复技力，所有干员的攻击回复技能持续时间内攻击力+50%」。
- **做法**（`server/sim/content/hexcards/stone_mode_modules_isw.js`；只有拥有这张卡的玩家、空弦装备**启用**的 ISW-
  模组时才生效）：
  - 「所有干员的攻击回复技能都享受该效果」：每 2.5 秒那一跳给**非狙击**的攻击回复干员 +1 技力；狙击那一份是基础
    天赋，仍在 kit（`kits/ops/chess_char_3_21-archet.js`）里 —— 两处按职业分开，同一名干员不会被给两次。
  - 「能被空弦的攻击回复技力」：空弦每攻击一次（一次攻击动作，S3 的 3 连击算一次），**自己以外**的、带攻击回复
    技能的己方干员各 +1 技力。
  - 「攻击回复技能持续时间内攻击力+50%」：拥有者自己的干员，自己的攻击回复技能在持续时 `atkPct +0.5`（技能结束 /
    空弦离场就撤掉）。
  - 数值读卡面 `params.modeModules`（`archetSpTickSec` / `archetSpTick` / `archetSpOnAttack` / `archetAtkPct`），
    缺省 = 官方数据 2.5 / 1 / 1 / 0.5。
- **测试**：`test/sim/hex-mode-modules-isw.test.js` 新增 5 条（2.5 秒那一跳扩到非狙击且不给狙击双份、空弦攻击喂
  队友且不喂自己、+50% 的挂 / 撤、真实棋子 + 3 级模组的 2.5 秒那一跳、真实 kit + 本模块各给一次）。
- **[ASSUMED]** 1) 空弦自己不因自己的攻击再拿一份 —— 她的攻击本来就按「攻击回复」给她 1 点；2) 「所有干员的攻击回复
  技能持续时间内」按「各自技能自己的持续时间内」读；3) +50% 是加算百分比（`atkPct`），不是乘算。
