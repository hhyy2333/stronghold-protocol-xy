## 暂未发布

### 修：塔露拉 2 技能的反伤打不到隐匿敌人（业主 2026-11-04）

- **现象**（业主 2026-11-04「修复一下塔露拉2技能反伤不能伤害隐匿敌人的bug」）：自选干员塔露拉（`char_4247_oxi`）的
  S2「阂断骤雪」被敌人打中时照常触发（庇护、叠层都对），唯独「对攻击来源造成塔露拉攻击力一定比例的范围法术伤害」
  这一下**对隐匿的敌人一点伤害都没有**。
- **根因**：S2 取反伤目标的两条路都写成了**索敌**——`Battle.foesInRadius`（范围效果能选中谁）与
  `canTargetEnemy`（索敌判定）都会剔掉未被阻挡的隐匿敌人（`targeting.js enemyStealthed`），于是目标列表里
  根本没有攻击者，循环空转、`dealt = 0`、连治疗都没有，`counter` 特效照放。
  **反伤不是索敌，是直接选中**：PRTS 异常效果「'直接选中'的能力…不受这些仅在选择时生效的异常效果制约」，
  PRTS 反伤备注也明写「反伤效果会直接选中伤害来源」。仓库里年 S2 铜印、斩业星熊 S1 恶业苦果、斥罪 T2 荆棘环身
  三处早就带 `ignoreSelect: true` 直接打来源，塔露拉这一份是唯一的例外。
- **修法**（`op-oxi.js`，只动 S2 (b) 两行）：攻击者本人仍进目标列表，但**不再过 `canTargetEnemy`**，其伤害实例带
  `ignoreSelect: e === src`；**它周围的溅射仍是范围判定**（继续走 `foesInRadius`），所以攻击者旁边另一个隐匿敌人
  照旧不吃这一下（PRTS 作战机制 §AOE伤害判定）。强度、类型、tag、治疗口径一字未改（倍率仍是该形态记录里的
  `retaliate_atk_scale`——rank 4 是 170%、rank 7 是 230%——法术、不可闪避、`tags: ['counter', …]`）。`ignoreSelect`
  只放开**对地规避**，`target.hidden`（隐身战场的「不可见」）仍由 `dealDamage` 开头拦下，这次改动不会让反伤越过
  隐身战场的隐藏单位。
- **测试**：`test/content/op_oxi.test.js` 新增一条「S2 阂断骤雪 反伤直接选中伤害来源」——一名**远程**（不被阻挡，
  所以真的还在隐匿）敌人挂 `flags: { stealth: true }`，先钉三条前提（它确实隐匿、`foesInRadius` 与
  `enemiesInKeys` 都不选它），再断言它照样吃满反伤且 `dmg.ignoreSelect === true`；后半段钉住**溅射仍是范围判定**：
  旁边的隐匿假人 `hp` 一点不掉。17/17（16 既有 + 1 新增）；关联套件 69/69（`feedback5-counters-any-damage` /
  `feedback2-stealth-splash` / `combat` / `op_judge` / `op_nian` / `op_hsgma2`）。把 `op-oxi.js` 的改动 `git stash`
  掉再跑这条会红，所以它钉的正是真根因。全量 sim 与全量 content 与改动前基线逐条相同（1306 例 / 1241 通过 /
  62 失败；2470 例 / 2413 通过 / 57 失败 —— 其中新增的 1 例是我的回归），无新增失败；golden 语料不含塔露拉，不移动。
