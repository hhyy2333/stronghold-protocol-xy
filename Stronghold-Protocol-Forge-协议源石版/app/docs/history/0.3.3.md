## 40. 上游 0.3.1–0.3.3 的修复移植

本节**不是**上游 §36–§38 的转抄：上游那三章（含 0.3.2 的分阶段结算内核与官方四版本）我们只挑了一部分搬，
逐条取舍与证据在仓库根的 `04-文档/上游0.3.3对比/`（总纲 `00-总纲与建议.md`、四份分报告 A–E、以及 `移植/` 下的交付总账）。
上游那三章若要整章搬，按本仓库的口径是 §38（0.3.1）/ §39（0.3.2）/ §40（0.3.3）——本节先占用 §40 号，
因为它记录的是"我们最终落到 0.3.3 这一版"的结果；§38 / §39 留给将来整章移植。

### 40.1 搬了：规则与结算（可复现的口径）

- **§40.1.1 穿透顺序**（上游 §37.30 / PR #798）：同一件伤害上固定穿透与百分比穿透同时存在时，**先减固定（不低于 0）、再乘百分比**。
  改前先乘后减，两类穿透叠加时会**多穿透**。落点 `server/sim/damage.js mitigate()`。上游实测 288 场景动 17 个
  （艾丽妮 / 圣聆初雪 / 迷迭香 / 送葬人 / Pith 这类同类叠加）。
- **§40.1.2 重入式 buff 移除**（上游 §37.5 / round49）：`onRemove` 里再移除别的 buff 时，按索引倒序遍历 live 数组会读到
  `undefined`（崩溃）或漏掉一个匹配项。改为先做快照、再按对象身份逐条定位删除。上游 golden **0 移动** —— 是崩溃修复，不是平衡。
- **§40.1.3 攻击类技能占用普通攻击的回合**（上游 §37.19 / §37.29 / §37.52 / §37.55）：技能"触发索敌和普通攻击相同"，
  就绪时按优先级选、同级随机；**没有攻击目标就不释放**（`_allowNoTarget` 的例外照官方）；**冷却从该技能动画结束时起算**；
  技能动画比攻击间隔长时下一次普攻等动画放完。昆图斯第三形态因此变成**大潮与普攻交替**（游戏内每 7.00 s 一次，原为 3.5 s 且普攻照常），
  断裂生殖在 7 段小队动作用完后不再释放；「自在」的【破桎而出】改为**需要目标**才展开屏障。
  落点 `server/sim/content/enemies.js`（`attackSlotSkill` / `attackTurnSkill` / `castNow` / `markAttackTurn`）与 `bosses.js`。

### 40.2 搬了：对局与敌人行为

- **§40.2.1 鸭爵「神秘顾客」每回合只抽一次**（上游 §37.26 / #839）：四人的替换数量、敌人与换成的种类相同，
  从本回合自身波次（不含悬赏敌人）中选。用 `ctx.seedFor('duck:<round>')` 的独立流。
- **§40.2.2 「进入休整期时」移到机变选择之后**（上游 §37.24 / §37.53 / #851）：老鲤第 3 回合的 2 / 4 阶干员、
  `preparation_start` 类策略与干员特质的「<进入休整期时>」都改在**休整期开始**发放，不再早于机变 draft。
- **§40.2.3 隐秘核心（R15）重新配对**（上游 §37.27 / #845）：首次规划用独立 salt（`boss-pairs:15`）且 `previous: null`，
  不再沿用最终攻势的搭档；该回合备战中有人退出时只为落单者重新配对。
  **有意偏差**：上游同时"随机洗牌分组与左右"，我们**不做** —— 本仓库 2026-10-16 的业主决定是**按座位序确定式配对**
  （座位小者在左半场），随机化会让客户端缺 `bossPairs` 时的兜底 `prepPair` 把摆人卡回道中。
- **§40.2.4 凯瑟琳突变细胞每玩家每局一次**（#677）：抽卡时排除已领取者，`pickReward` 里计数。
- **§40.2.5 联防只给漏过来的那一波记账**（#675）：场上才出生的（分裂 / 召唤的）子体不再被当逃逸者抬 ×N 扣目标生命；
  运行时子体打 `uniteRuntime` 标记，leak 记录带出该标记，结算只统计原本就在这一波里的敌人。
- **§40.2.6 血珀**（上游 §37.107 / #720）、**心虚设计师**（§37.108 / #869）、**淤困**（§37.95 / #803）：
  血珀在场上没有唤血祭坛 / 沥血王座时每秒流失 10 % 最大生命（真实流失、可致死、不吃 DEF / RES / 闪避 / 屏障，仍自缚、失衡免疫、不攻击、不可阻挡）；
  心虚设计师被阻挡时正面朝向**阻挡者那一侧**（80 % 减伤跟着转），未被挡时朝走路方向，同一列的阻挡者保持上次朝向 [ASSUMED]；
  淤困附着时**闪现到阻挡者格心并自缚**。朝向与瞬移的客户端半边见 §40.3.4。

### 40.3 搬了：表现与客户端

- **§40.3.1 本地化下的规则读数**（上游 0.3.1 #676 / #700 —— 本次最"物有所值"的一条，因为**我们本来就中招**）：
  高台部署与攻击范围预览原来**在翻译后的文本上**做匹配（`可以放置于远程位` / `攻击范围扩大` 等中文串），
  于是 en / ja / ko / 繁中界面下 歌蕾蒂娅 / 崖心 / 见行者 一律判成"地面"、范围预览也算错，而服务端照收 —— 前后端不一致。
  现在 `public/js/data.js` 在生成本地化副本时**从未翻译的原记录**派生 `placeOnRanged` / `passiveRange` / `rangeExpand` / `modeOnly` 旗标，
  `shared/highGround.js` 与 `shared/loadoutRecord.js` **旗标优先、中文文本兜底**。中文路径逐字节不变（266 棋 × 全部 loadout = 1601 组 0 差异）。
- **§40.3.2 商店装备位**（上游 §38.1）：服务端私有视图补发 `shop.layout = { chess, item }`，客户端按**实际位数**分栏；
  空装备位画空卡而不是「已购买 / 已售罄」。不照抄上游 `layout.item === 0` 仍画售罄卡那一处（上游自身不自洽）。
- **§40.3.3 贴图缓存身份**（上游 §38.3）：道具贴图缓存**按解析出来的图 URL** 存，不再按 item id；
  补位 / 自选编队的合成记录缓存也比对源对象（`chess` / `backups`）后才复用。
- **§40.3.4 敌人技能动画与攻击回合的表现**：模型 → 官方技能 clip 的表补全（昆图斯大潮 = `Skill_02` / 崩坍 = `Skill_01`，
  改前两者**互换**；胄死亡集群、泥岩两槽、自在、斩胄 / 破胄、锏、阿利斯泰尔同理）；干员普攻片段按官方动画表修正
  （德克萨斯 / 伺夜 / 归溟幽灵鲨 / 焰影苇草 / 耀骑士临光 / 瑕光）；`cast` 事件加**可选第 5 字段 `turnClip`**，
  客户端在攻击回合内播该槽位的官方剪辑并跳过这一回合的普攻动画（不声明就没有，旧形状逐字节不变）；
  逐 tick 朝向走 `b.snap.face` 的可选列表，淤困的 `teleport` fx 切断插值。

### 40.4 没搬（明确记录，省得以后重查）

- **分阶段结算内核**（上游 §37.32 / §37.33 / §37.34 / §37.35，`server/sim/attack/`）：上游这一节就动 118 / 288 场景，
  且我们的自有内容（协议源石 / 债务 / 灵魂炸弹 / 百变…）挂在同一批钩子上；这是 L 级、要单独立项。
  折中已经落地的是 §40.1.1（公式级）—— 后续候选是"只把 `absorbShields` 拆成有序伤判队列"与"红字改比最终伤害"。
- **官方四版本**（`data/versions/` + 房间版本投票 + 一版一进程）：我们是「单季 + 自有内容」结构，多一版等于把自有内容叠三遍。
  若将来要第一期老内容，正路是"并入单套数据"，不是上 `config.version`。
- **`PLUGIN_API` 抬到 3**：它本质是分阶段结算的下游（钩子语义随阶段重定义），单独抬等于放行语义对不上的插件。
- **皮肤呈现层 / 测试房间 / 结算页与事件 UI 重排**：本仓库有自研替代或 UI 已整体分叉。
  唯一与业主决定正面冲突的是上游 0.3.1 的「琳琅诗怀雅 S3 回官方无限持续」——本仓库保持 2026-10-04 的决定。

### 40.5 版本号口径

`APP_VERSION` **0.19.36 → 0.19.37**（自己的发布号）；`UPSTREAM_VERSION` **'0.3.0' → '0.3.3'**（跟随的官方版本）；
`PROTOCOL_VERSION`（2）与 `MOD_API_VERSION`（1）**都没动** —— 本轮只加了一个可选事件字段（`cast` 的第 5 位），
不声明就没有。golden 语料不在本 checkout（`test/golden/` 缺失），发版前必须在完整仓复算一遍。
