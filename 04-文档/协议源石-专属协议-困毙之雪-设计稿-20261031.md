> 日期：2026-10-31。业主原话见 §1。范围：谢拉格新增一张**盟约专属协议源石**（2 阶 / gold，`requiresBond: kjeragShip`），
> 与【衰朽的骄矜】【炎百兽】同批。数值全部写进卡面 `effect` 参数（`tools/hextech/roster.mjs`），战斗模块只读参数。

## 0. 已确认事实（业主 2026-10-31 答复）

- 做成 **2 阶专属协议源石**（`requiresBond: kjeragShip`），不是改盟约本体。
- 霜寒到 5 层进入冰封：**消耗 5 层清零**；**冰封期间不叠霜寒**；冰封结束后从 0 重新叠。
- 「冰封干员阻挡的敌人每秒受到 100 点真实伤害（每层 +40）」的「每层」= **谢拉格盟约层数 L**（即 `100 + 40L`）。
- 6 名档「对所有敌人每秒 100（随层数 +50）真实伤害」= **谢拉格盟约层数 L**（即 `100 + 50L`）。
- 3 名档「敌人冻结结束时…该敌人周围所有谢拉格干员」的「周围」= **半径 1.5**。

## 1. 业主原文

> 谢拉格盟约效果：「困毙之雪」
> 〖谢拉格〗干员冻结敌人时，获得1层霜寒。每层霜寒：防御力+5%，但攻击速度-5。
> 霜寒达到5层时，干员进入 「冰封」：无法攻击、无法使用技能、无法被治疗，但阻挡数+1且免疫所有伤害。持续5s
>
> <在场3名不同〖谢拉格〗干员>——变革的残响
> 解锁霜寒机制。
> 每有1层霜寒，攻击时有30%概率施加寒冷。
> 敌人冻结结束时未被击杀，则该敌人周围所有〖谢拉格〗干员获得1层霜寒。
> 若场上没有任何敌人处于冻结状态，所有〖谢拉格〗干员每5秒累积1层霜寒。
> 冰封干员阻挡的敌人每秒受到100点真实伤害（每层+40）
> <在场6名不同〖谢拉格〗干员>——困毙之雪
> 〖谢拉格〗干员死亡时，冻结全场敌人5秒，并为全体〖谢拉格〗干员移除2层霜寒。
> 若场上所有〖谢拉格〗干员同时处于冰封状态，则对所有敌人每秒造成100（随层数+50）的真实伤害并施加寒冷，持续15秒

## 2. 卡面参数（`effect.kjeragFrostDeath`）

```js
kjeragFrostDeath: {
  unlockCount: 3,              // 3 名不同谢拉格：解锁霜寒机制
  frostMax: 5,                 // 5 层进冰封
  defPctPerStack: 5,           // 每层：防御 +5%
  aspdPerStack: 5,             // 每层：攻速 -5（点数）
  sealSec: 5,                  // 冰封持续
  coldChancePerStack: 30,      // 每层：攻击时 30% 施加寒冷（叠乘，封顶 100%）
  coldSec: 5,                  // 施加寒冷的持续时间 [ASSUMED]
  freezeEndRadius: 1.5,        // 冻结结束时「周围」半径
  idleFrostSec: 5,             // 场上无冻结敌人时，每 5 秒 +1 层
  sealedBlockDmg: 100, sealedBlockDmgPerLayer: 40,   // 冰封干员阻挡的敌人每秒真实伤害 = 100 + 40L
  highCount: 6,                // 6 名不同谢拉格
  deathFreezeSec: 5,           // 谢拉格死亡：冻结全场敌人 5 秒
  deathRemoveStacks: 2,        // 并移除全体谢拉格 2 层霜寒
  allSealedDmg: 100, allSealedDmgPerLayer: 50,       // 全冰封：每秒 100 + 50L 真伤
  allSealedSec: 15,            // 全冰封真伤持续 15 秒
}
```

## 3. 实现口径

- **作用域**：拥有该卡的玩家自己的【谢拉格】干员（`isMember(battle, u, 'kjeragShip')` + `u.ownerId === pid`）。
  「在场」= `alive && deployed && !hidden`（`hexHooks.onField`）。N = 场上己方谢拉格干员按 `baseChessId` 去重。
- **霜寒（每名干员独立）**：一个 `refresh: 'stack'` 的 buff（key `hex:kjeragfrost:frost`，maxStacks 5）：
  `mods: { defPct: 0.05, aspd: -5 }`（引擎的加算 mod 按层数乘值 ⇒ 5 层 = 防御 +25%、攻速 -25）。
  `stacks` 就是霜寒层数。**N < 3 时完全不解锁**（不叠、不触发冰封、攻击不施寒冷）。
- **获得霜寒**（N ≥ 3，且该干员不在冰封中）：
  1. 冻结敌人时：`statusApplied` 钩子，`status === 'freeze'`、`entered === true`、`target.side === 'enemy'`、
     `source` 是己方谢拉格干员 ⇒ 该干员 +1 层。
  2. 冻结结束未被击杀：每 0.25s 轮询敌人的 `freeze` buff，记录「上一拍冻结 / 这一拍不冻结且还活着」的敌人
     ⇒ 该敌人半径 `freezeEndRadius`（1.5）内所有己方在场谢拉格干员各 +1 层。
  3. 场上没有任何敌人处于冻结状态：`battle.every(5)` 检查全场敌人没有 `freeze` buff ⇒ 所有己方在场谢拉格干员 +1 层。
- **冰封**：某干员霜寒到 5 层 ⇒ 移除霜寒 buff（清零）、挂 `hex:kjeragfrost:seal`，持续 5s：
  `flags: { disarm: true, silence: true, noHeal: true, healFree: true, invulnerable: true }`、`mods: { blockCnt: 1 }`。
  冰封期间不再获得霜寒。结束后从 0 重新叠。`[ASSUMED: 「无法被治疗」= noHeal + healFree；冰封不是晕眩，仍然阻挡]`
- **攻击施寒**（N ≥ 3）：`hit` 钩子里，来源是己方谢拉格干员、目标敌方、这一击不是 元素/流失/反伤/链式，
  概率 = `min(1, coldChancePerStack/100 × 霜寒层数)`（`battle.rng()`），命中则 `applyStatus(target,'cold',{ duration: coldSec, source: unit })`。
  层数为 0 时不掷骰。
- **冰封干员阻挡的敌人**：`battle.every(1)`，对每个带 `seal` buff 的己方谢拉格干员，遍历 `u.blocking` 里
  `e.blockedBy === u` 的敌人，造成 `sealedBlockDmg + sealedBlockDmgPerLayer × L` 真实伤害（来源 = 该干员，tags 标 `hex`）。
- **6 名档 · 死亡**：`death` 钩子，`c.unit` 是己方谢拉格干员且 `c.reason === 'killed'` ⇒
  对全场活着的敌人 `applyStatus('freeze', { duration: deathFreezeSec, source: 该干员 })`；
  对全体己方谢拉格干员移除 `deathRemoveStacks` 层霜寒（`stacks -= 2`，≤0 就移除 buff）。
- **6 名档 · 全冰封**：每 0.25s 检查「场上至少 1 名己方谢拉格干员、且全部带 `seal` buff」⇒ 启动 15 秒的每秒脉冲：
  对全场敌人造成 `allSealedDmg + allSealedDmgPerLayer × L` 真实伤害并 `applyStatus('cold', { duration: coldSec })`。
  脉冲期间不重复启动；结束后可再次触发。`[ASSUMED: 真伤来源记为该玩家第一名冰封干员；cold 用 coldSec]`
- **确定性**：随机只用 `battle.rng()`；计时只用 `battle.every` / `battle.after`；无 `Math.random` / `Date` / Node API。

## 7. 落地补充（2026-10-31 实现时定下的口径）

实现见 `server/sim/content/hexcards/stone_kjerag_frostdeath.js`（`installKjeragFrostDeath`），测试
`test/sim/hex-stone-kjerag-frostdeath.test.js`（16 条）；接线冒烟 `test/sim/hex-stone-wiring.test.js`（11 张卡同场）。

- **霜寒**是一个 `refresh:'stack'` 的 buff（`stacks` 即层数），引擎的加算 mod 按 stacks 乘值 ⇒ 5 层 = 防御 +25% / 攻速 −25。
- **冰封**不是晕眩：不加 `stun`，仍然阻挡；`flags: disarm / silence / noHeal / healFree / invulnerable` + `blockCnt: 1`，
  靠 buff 自己的 5 秒时长结束。冰封期间 `gainFrost` 直接返回（不叠层），结束后从 0 重新叠。
- **解冻回层**的半径用场上坐标的欧氏距离 ≤ 1.5（不取整到格子）；「冻结结束」用 0.25 秒轮询 `freeze` buff 判定。
- **本卡自己打出的真伤**带 tag `hex:kjeragfrost`，`hit` 钩子见到它不再掷寒冷 —— 否则会用自己的真伤给自己喂寒冷 / 冻结。
- **6 名档的死亡判定**把刚阵亡的那名干员算进 N（否则「第 6 名倒下」永远凑不满 6 名，这一档永远不触发）。
- 全冰封脉冲的真伤 / 寒冷来源记触发那一刻的第一名冰封干员；15 拍后停止，之后可再次触发。

### 8.4 本次新增的 [ASSUMED]

1. 「周围八格」= 切比雪夫距离 ≤ 1 的格心判定（与【惊惧】/【泰拉在上】同口径），`sealedAuraRadius` 可调。
2. 多名冰封干员的八格**会重叠**：每个冰封干员各打自己一发（同一敌人站两个冰封干员中间 ⇒ 每秒挨两发）。
3. 击杀返层按**敌人条数**：一发同时打死 n 名 ⇒ +n 层（6 名档 +2n）；只认「这一发打之前活着、打之后倒下」。
4. 返层走 `battle.addLayers`：联防 / 首领 / 隐藏场（`layerGainsEnabled === false`）由引擎自己拒绝。
5. 6 名档死亡那一发的**冻结**本身会触发 3 名档的「全体 +1 层」，所以净变化 = 新冻上的敌人数 − 4
   （场上有没被冻过的敌人时实际掉 3 层）。要求严格净 −4 就把移除挪到冻结之前。
