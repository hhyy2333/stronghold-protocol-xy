# 协议源石 · 专属协议【骑士金神】· 设计稿（实现口径）

> 日期：2026-10-31。业主原话见 §1。范围：卡西米尔新增一张**盟约专属协议源石**（2 阶 / gold，`requiresBond: kazimierzShip`），
> 与【衰朽的骄矜】【炎百兽】【困毙之雪】同批。数值全部写进卡面 `effect` 参数（`tools/hextech/roster.mjs`）。

## 0. 已确认事实（业主 2026-10-31 答复）

- 做成 **2 阶专属协议源石**（`requiresBond: kazimierzShip`），不是改盟约本体。
- 「敌人增加」按**卡西米尔盟约层数 L** 分档、**累计**：
  `<50` 额外刷 1 只【无胄盟清扫小队】；`50–100` 再 +1 只【无胄盟清扫小队】（共 2）；`100–200` 再 +1 只【烛骑士薇薇安娜】；
  `200–300` 再 +1 只【腐败骑士】；`300–400` 再 +1 只【凋零骑士】；`≥400` 不再增加。
  7 名档**不再**额外加敌人（刷怪表就是全部，5 名档起生效）。
- 「攻击范围扩大」= **+1 格**（`rangeExtend` +1）。
- 「本回合每消耗 3 金，所有干员伤害提升 20%」= **可无限叠**（按 3 金一档取整）、**只在本回合有效**，下一回合清零。
- 击杀金币：**全队共享计数**（所有己方【卡西米尔】干员的击杀合在一起，每 4 杀 +1 金）；每场最多
  `min(9, 1 + floor(L/50))` 金（L = 卡西米尔盟约层数）。
- 「等阶最高的干员」：并列最高**都加**。

## 1. 业主原文

> 卡西米尔盟约效果：「骑士金神」
>
> 〖卡西米尔〗干员击杀4个敌人时获得1金（每场战斗最大1，每50层＋1，最多＋到9）。
>
> <在场5名不同〖卡西米尔〗干员>
> 敌人增加。
> 等阶最高的干员攻击力+30（每层＋1），攻击范围扩大；
> <在场7名不同〖卡西米尔〗干员>
> 敌人增加。
> 本回合每消耗3金，所有干员伤害提升20％

## 2. 卡面参数

```js
effect: {
  kazimierzKnightGold: {
    killStep: 4,                       // 每 4 杀 +1 金
    goldBase: 1, goldPerLayer: 50, goldCap: 9,   // 每场上限 = min(9, 1 + floor(L/50))
    highCount: 5,                      // 5 名不同卡西米尔
    atkFlat: 30, atkPerLayer: 1,       // 攻击力 +30 + 1×L
    rangeExtend: 1,                    // 攻击范围 +1 格
    enemyTiers: [                      // 累计：每档 min ≤ L 就刷 count 只
      { min: 0,   key: 'enemy_1183_mlasrt',    count: 1 },   // 无胄盟清扫小队
      { min: 50,  key: 'enemy_1183_mlasrt',    count: 1 },   // 再 +1 只
      { min: 100, key: 'enemy_1184_cadkgt_3',  count: 1 },   // 烛骑士薇薇安娜
      { min: 200, key: 'enemy_1513_dekght',    count: 1 },   // 腐败骑士
      { min: 300, key: 'enemy_1513_dekght_2',  count: 1 },   // 凋零骑士
    ],
    sevenCount: 7,                     // 7 名不同卡西米尔：金币伤害
  },
  // 备战侧（server/sim/content/hextech.js applySpec）：
  onSpend: { goldDamage: { per: 3, pct: 20 } },
  onRoundStart: { goldDamageReset: true },
}
```

## 3. 实现口径

### 3.1 备战侧（Lead 负责，`server/sim/content/hextech.js applySpec`）

- `onSpend.goldDamage { per, pct }`：每次消费 `ev.amount` 金累加到本卡自己的计数器（`hex:<id>:goldspent`，每回合重置），
  并把 `floor(spent/per)*pct` 写进本卡 EffectRef 的 `params.battle.dmgPct`（`ctx.addEffect`，与【传承】的
  `params.battle.bondAtk` 同一写法）。
- `onRoundStart.goldDamageReset`：把计数器与 `params.battle.dmgPct` 清零（「本回合」只在本回合有效）。
- 战斗输入照常带 `params.battle.dmgPct`；战斗侧读它。

### 3.2 战斗侧（队友负责，`server/sim/content/hexcards/stone_kazimierz_knightgold.js`）

- **作用域**：拥有该卡的玩家自己的【卡西米尔】干员（`isMember(battle, u, 'kazimierzShip')` + `u.ownerId === pid`）。
  「在场」= `alive && deployed && !hidden`；N = 场上己方卡西米尔按 `baseChessId` 去重。
- **击杀金币（无门槛）**：`kill` 钩子，`victim.side === 'enemy'` 且 `killer` 是己方卡西米尔干员 ⇒ 全队计数 +1；
  每满 `killStep`（4）次，`battle.addCoins(pid, 1)`，直到本场已发放数达到 `min(goldCap, goldBase + floor(L/goldPerLayer))`
  （L 取实时 `bondLayers`）。击杀计数跨干员共享、跨死亡保留（挂在 per-battle store / `battleStore`）。
- **5 名档 · 敌人增加**：`battleStart`（优先级 -10）按 `enemyTiers` 里 `min ≤ L` 的每一档，`battle.spawnEnemy(key, { routeIndex: 0, tag: 'hex:knightgold' })`
  （累计）。这些是运行时刷怪，不进 HUD 分母 / 备战预览 `[ASSUMED]`；不加敌方缩放 `[ASSUMED]`。
- **5 名档 · 等阶最高**：场上己方卡西米尔干员里 `tierOf(u)` 最高的那些（并列都算）挂常驻 buff
  `hex:knightgold:high`：`{ atkFlat: 30 + 1×L, rangeExtend: 1 }`；`battleStart` / `deploy` / `layerGain` 后刷新
  （层数变了要重算；阶位不会变）。
- **7 名档 · 金币伤害**：N ≥ 7 时，读本卡 EffectRef 的 `params.battle.dmgPct`（备战侧写入），给**所有己方干员**
  （不只卡西米尔）挂常驻 `dmgDealtMul: 1 + dmgPct/100`（`battleStart` / `deploy` 补装）；dmgPct 为 0 时不挂。
- **确定性**：随机只用 `battle.rng()`（本卡其实不需要随机）；计时只用 `battle.every` / `battle.after`。

## 7. 落地补充（2026-10-31 实现时定下的口径）

实现见 `server/sim/content/hexcards/stone_kazimierz_knightgold.js`（`installKazimierzKnightGold`），测试
`test/sim/hex-stone-kazimierz-knightgold.test.js`（18 条）；备战半段在 `server/sim/content/hextech.js applySpec` 的
`goldDamage` / `goldDamageReset`（测试：`test/content/hextech.test.js` 的 ctxStub 一条 + `test/match/hex-exclusive.test.js`
的真实 dispatcher 一条）。

- **击杀金币**：全队共享计数挂 `battleStore`（跨干员、跨死亡保留）；每 4 杀 `battle.addCoins(pid,1)`，每场上限
  `min(9, 1 + floor(实时卡西米尔层数/50))`；一次多杀会把该补的金补齐。只认**干员**亲手击杀（召唤物 / 无来源不算）。
- **刷怪**：`battleStart`（优先级 -10）按 `enemyTiers` 里 `min ≤ L` 的每一档累计刷 `count` 只（`spawnEnemy`，`routeIndex: 0`）；
  运行时刷怪 `inTotal` 保持 false（不进 HUD 分母 / 备战预览），也不加敌方缩放 `[ASSUMED]`。
- **等阶最高**：`tierOf` 并列最高的己方卡西米尔都挂 `{ atkFlat: 30 + L, rangeExtend: 1 }`；条件不满足按同键撤销。
- **金币伤害**：读本卡 EffectRef 的 `params.battle.dmgPct`，N≥7 时给所有己方干员 `dmgDealtMul: 1 + pct/100`；
  备战侧 `onSpend` 累加、`onRoundStart` 清零（真实 dispatcher 实测：消费 3 金 → 20、累计 7 金 → 40、新回合 → 0）。
- 策略「管理员」复制成两份时两个常驻 buff 同键 ⇒ 两份副本不叠加（卡面无「每份叠加」写法）。
