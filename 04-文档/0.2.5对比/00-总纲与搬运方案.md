##### 2.2.1 `public/js/ui/components.js` — `Tooltip`（唯一真特性撞车）

两边都在改同一个组件，**不是二选一，是必须把两个特性并到一起**：

- **官方 0.2.5 改的**：给 `Tooltip` 加**复合提示框 `aside`** —— `tipState` 增 `aside`；`Tooltip({ text, aside = null, ... })`；`asideRef`；`setTip({…, aside, hold, hide })`；`TooltipLayer` 加 `pointerdown` / `Escape` / `resize` 监听、贴边夹取、`tabIndex` 与 `onFocusIn/onFocusOut`；新样式 `tooltip--compound` / `tooltip__main` / `tooltip--aside`。
- **你的改版改的（同一处）**：给 `Tooltip` 加**触屏点击展示 `tapShow`** —— JSDoc 重写；`TOUCH_TIP_HOLD_MS`(1600) / `TOUCH_TAP_HOLD_MS`(3000) / `TOUCH_TAP_SLOP`(10)；`Tooltip({ …, tapShow = false, … })`。
- **怎么合**（E 区已核实到行，此处采其结论）：
  1. 签名合并为
     `export function Tooltip({ text, aside = null, placement = 'top', delay = 120, block = false, class: cls, tapShow = false, children }) {`
  2. JSDoc 合并两边段落，`aside` 与 `tapShow` 都保留。
  3. 官方的 `asideRef` / `hold` / `hide` / 监听器 / 夹取逻辑保留。
  4. ⚠️ **定时器归属别搞反**（最容易合错的一处）：
     - 我方 `components.js` 里有**两个** ref：`timer.current` 放「显示延迟」与长按松手宽限，**`hideTimer.current` 专放 `TOUCH_TAP_HOLD_MS`**（我方第 565/572/574/582/583/618/619 行）。

## 8. ⚠️ 一条会污染全队的坑：官方 `docs/` 里的链接是打包产物

**F 区实测**：`参考对象\...-update` 里的文档不是纯源码树，而是**打包器裁剪后的玩家包**。证据：

- 更新包 `package.json` **没有** `lint` / `check:imports` / `typecheck` 脚本，而 `base-025\.github\workflows\ci.yml` 却在调用它们——官方源码不可能自相矛盾。
- 删掉的那 10 个 npm 脚本是打包器 `PLAYER_NPM_SCRIPTS` 白名单行为，**不是 0.2.5 的源码改动**。
- 实测 `base-025\README.md` 含 **18 处** `blob/v0.2.5/` 形式的绝对链接，而 `base-024\README.md` **0 处**——这些是打包时做的链接改写。

**结论（影响全队）**：所有 `docs/*.md`、`README.md`、`CHANGELOG.md` 里指向 GitHub 的**绝对链接一律不要抄**；只抄正文段落。`package.json` 的**删脚本**动作也不要跟。
- **不要**搬 `node_modules/.package-lock.json`（纯换行符差异，搬了没意义）；依赖没变，**不需要 `npm install`**。
- **不要**把 `CHANGELOG.md` / `README.md` 的官方版本覆盖上去——那是官方自己的历史，一覆盖我的记录就没了。手动摘抄 0.2.5 段落即可。
