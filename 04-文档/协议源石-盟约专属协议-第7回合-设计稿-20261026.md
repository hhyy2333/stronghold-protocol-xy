# 协议源石 · 盟约专属协议（第 7 回合）· 设计稿

> 日期：2026-10-26。范围：第 7 回合改为「盟约专属协议源石」抽取回合；增强【锻炉】；为其余 7 个核心盟约各设计 1 张专属协议源石。
> 本稿是**实现口径**，不是效果审阅稿；未定项按仓库惯例标 `[ASSUMED]`，落地后可单独调数。

## 0. 已确认事实（实读代码/数据）

- 协议源石抽取回合由 `data/hextech.json` 的 `format.rounds` 决定，当前 `[1,3,6,11]`；服务端入口 `server/match/match/hexDraft.js`。
- 「专属协议」已有字段 `requiresBond`：只在该盟约**当前激活**时才会被抽到（`server/match/hextech.js hexAvailableTo` / `hexPoolFor`），实现先例为【锻炉】`hex_forge`（`requiresBond: 'victoriaShip'`，2 阶）。
- 盟约层数上限 999；层数读取用 `bondLayers(battle,pid,bondId)`；战斗内加层用 `battle.addLayers(pid,bondId,n,reason,{source})`；备战侧层数变化钩子是 `onLayers`。
- 部署位：`ps.deployCap`（默认 8），备战侧原语 `ctx.addDeployCap(n)` 已存在。
- 灼燃爆发：`server/sim/damage.js resolveBurst`，敌人侧 7000 元素伤害；`hit` 钩子可在结算前改 `dmg.amount`。
- 寒冷/冻结状态键：`cold` / `freeze`；减速 `slow`（value = 速度削减比例，0.6 ⇒ 60%）。
- 弹药：`skill.ammoLeft`，消耗事件 `ammoUsed`，致命事件 `fatal`（`c.prevented = true` 免死）；次数盾 = buff `shieldHits`。
- 护盾：buff 的 `shield`（数值屏障）/ `shieldHits`（次数盾），`battle.addBuff` 同名刷新。
- 真伤：`dmg.type === 'true'`；伤害转移已有引擎助手 `applyRedirectCut` / `redirectShare`（`server/sim/damage.js`，坚守在用）。
- 不屈：`indomShip` 盟约，层数越高复活概率越高；「+5 不屈」按 **+5 层** 实现 `[ASSUMED]`。
- 获得干员/装备：备战侧 `ctx.grantChess(id)` / `ctx.grantItem(id)`；卡面 spec 现有 `chess`（按阶随机）与 `item.ids`（指定装备）。
- 现有干员 id：薄绿 `chess_char_3_08_a`、洛洛 `chess_char_2_10_a`、耶拉 `chess_char_3_20_a`、安洁莉娜 `chess_char_5_20_a`、缇缇 `chess_char_5_02_a`（「提提」按【缇缇】理解 `[ASSUMED]`）；黄沙罗盘 `chess_item_6_07_e_a`。
- 新装备【骑士徽章】需新增 `tools/build-data.mjs` CUSTOM_ITEMS 记录 + `server/sim/content/items/protocol.js` 行为。

## 3. 七张盟约专属协议

> 统一：`requiresBond` = 对应核心盟约；新卡 3 阶（棱彩）`[ASSUMED]`；【锻炉】保持 2 阶。
> 每张卡的数值都写进 `effect` 参数，战斗模块只读参数，方便后续调数。

### 3.1 炎 ·【燎原】`hex_yan_ember`（3 阶）

- 获得时：可部署人数 +2。
- 作战中：己方干员造成伤害时，附加相当于攻击力 2% 的灼燃损伤（每名干员每秒至多 1 次）。
- 【炎】≥200 层：灼燃爆发伤害翻倍。
- 【炎】≥300 层：【炎】干员视为【坚守】干员（非【炎】友方受到伤害的 40% 由【炎】干员平均承担；【炎】干员受伤时对来源造成 850+10×层数 法术伤害并施加 40% 脆弱 5 秒，0.2 秒冷却）。
- 参数：`yanEmber: { burnPct: 2, burstLayer: 200, steadLayer: 300, steadRatio: 40, thorn: 850, thornPerLayer: 10, fragile: 40, fragileSec: 5, cd: 0.2 }`。

### 3.2 萨尔贡 ·【绿洲】`hex_sargon_oasis`（3 阶）

- 作战中：【萨尔贡】干员释放技能时，获得相当于攻击力 100% 的护盾；其下一次攻击额外造成等同当前护盾值的法术伤害（一次技能一次）。
- 【萨尔贡】首次达到 60 层：获得干员【缇缇】；首次达到 325 层：获得装备【黄沙罗盘】。
- 参数：`sargonOasis: { shieldPct: 100, layerChess: 60, layerItem: 325 }`。
- 备战侧 60/325 由 `onLayers` 里程碑 spec 处理（每档一次）。

### 3.3 谢拉格 ·【冰雪消融】`hex_kjerag_thaw`（3 阶）

- 获得时：获得干员【耶拉】；所有【谢拉格】干员价格 −1（最低 1）。
- 作战中：【谢拉格】干员攻击寒冷/冻结敌人时，解除其寒冷/冻结，获得 1 层谢拉格；这次伤害提升至 130%（寒冷）/260%（冻结），并施加 40% 减速 6 秒。
- 【谢拉格】≥75 层：【谢拉格】干员攻击力 +50%、生命值 +50%。
- 参数：`kjeragThaw: { layers: 1, coldMul: 130, frozenMul: 260, slowPct: 40, slowSec: 6, buffLayer: 75, atkPct: 50, hpPct: 50 }`。

### 3.4 拉特兰 ·【圣佑】`hex_laterano_sanctuary`（3 阶）

- 作战中：【拉特兰】干员每消耗 1 颗弹药，回复所有【拉特兰】干员 5% 最大生命。
- 【拉特兰】干员受到致命伤害时，若仍有弹药：消耗全部弹药，免疫本次伤害，并获得 1 层次数盾。
- 参数：`lateranoSanctuary: { healPct: 5, shieldHits: 1 }`。

### 3.5 阿戈尔 ·【协同进化】`hex_egir_symbiosis`（3 阶）

- 作战中：【阿戈尔】的吞噬不再造成伤害。
- 吞噬结束后：【阿戈尔】干员的攻击力、最大生命提升至（高了不降低）阿戈尔干员最大值的 80%。
- 参数：`egirSymbiosis: { statPct: 80 }`。
- 需要 `server/sim/content/bonds/core.js` 的 devour 读取该卡：有卡则不结算 5000 物理流失，并在最后一次吞噬结束后 emit `egirDevourEnd`。

### 3.6 叙拉古 ·【教父】`hex_siracusa_godfather`（3 阶）

- 获得时：获得干员【安洁莉娜】。
- 作战中：己方干员造成伤害时，使敌人 +10% 易伤，最高 +200%（同名取最高，永久本场）。
- 参数：`siracusaGodfather: { vulnPct: 10, maxPct: 200 }`。

### 3.7 卡西米尔 ·【骑士】`hex_kazimierz_knight`（3 阶）

- 获得时：获得装备【骑士徽章】。
- 【骑士徽章】：装备者（下称「骑士」）获得：
  - 【卡西米尔】干员受到伤害时，伤害转移给骑士（100%）；
  - 【卡西米尔】干员造成的真实伤害 ×2；
  - 【卡西米尔】干员受到致命伤害时，+5 层【不屈】，并锁血 5 秒（期间不会死亡）。
- 参数：`kazimierzKnight: { transferPct: 100, trueMul: 2, indomLayers: 5, lockSec: 5 }`；装备记录参数同源。
- 新装备：`chess_item_9_98_e_a`【骑士徽章】（1 阶、价格 0、商店不出售、不可合并）。
