## §0 一句话

**值得吸取的东西不到这个包的百分之一。** 它 = 「上游 vanilla 0.3.3 + 四个社区整合包 + 一个自研桌面壳 + Forge 编辑器子树」的合并成品。代码层的 99% 是上游，而 10-30 已经对过上游、结论是「三件大件不搬」；插件平台那套机制我方**同血脉、同版本上限**，不是它的贡献。

**真正新的、能拿的只有三件：**

1. **开场动画**（`allianceScene.js` + `lobbyIntro.js`）—— 素材/音频/字体我方全有，纯新增，`main.js` +3 行，**S**，且不碰任何界面布局（[C §2](C-表现层.md)）；
2. **皮肤的「决策层」**（选择器 + 存储 + 一个外观提供者）—— 我方通道 3/4 早通，只差这一层；**S**，做完玩家就能换头像/立绘（[B §1.2](B-插件与皮肤.md)）。这是本次唯一一条**改了 10-30 老结论**的发现；
3. **桌面壳「只做无窗口、不做内嵌窗口」这个判断**（不是抄它的实现）—— 它自己在本机就是崩的（`launcher.log:2-12` 一次 WebView2 `COMException 0x8000FFFF`），**S–M**（[A](A-桌面启动器.md)）。

再往下一档是 **302 套官方时装素材**（276/302 我方有对应干员、248 套带得动局内模型，+344 MB，**M**，要业主拍板）与 **7 个 S 级小件**（§4）。同时有 **6 条「别照抄」的坑**（§5）——其中 `csp:"off"`、`/img-proxy`、`install.mjs` 三条是会**降低安全性或回退版本**的。

**发行工程、包完整性、诊断、单实例、文档一致性这五项我方已经领先**（§6）。别为了「像它一样有个 exe」把这些换掉。

## §3 三件"值得做"到底值多少

### 3.1 开场动画（唯一"零风险"的一件）

它是一段**逐帧打表的 DOM 动画**（按官方活动录屏 30 fps 重建，`allianceScene.js:1-8`），一个 `<dialog>` 覆盖层，播 2.8 秒淡出到下面的页面。为什么是 S：

- **依赖逐项核过，全在我方树里**：8 张 `entry/*` + `prepareBkg/*` 贴图（`data/assets.json` 有键、`public/assets/ui/` 有文件）、入场音效 `act1autochess_g_ui_load.mp3`、Bender 字体（`public/fonts/bender-*.woff2`）、`audio` 的 9 个接口（连 `resolveBgm(…,'lobby')` 返回 `{intro, loop}` 的形状都一样）。
- **它是 modal，不看也不改页面里有什么**：所以「我方标题页/大厅布局与那份 0.2.4 分支不同、硬套会丢功能」这条风险**在它身上不成立**。真正会丢功能的是另一件事：顺手把它的 `title.js`(297)/`lobby.js`(808) 换过来 —— 我方是 302/**1415** 行，换过去等于删掉素材包下载、通知/语言/全屏、局域网找房、无限火力、协议源石禁用入口等半屏功能。**这条边界要写进任务单。**
- 唯一真正的技术活：把它的 `resourcesReady() => true`（因为上游素材由服务器发）换成我方的真闸门 —— **8 张 sprite 全部 decode 成功才播，否则静默跳过**（我方有「素材没下载」的机型）。
- 文档别信：`PACKAGING.md:146` 还写着「第一次要点一下 TAP TO START」，但 `lobbyIntro.js:104-112` 早已改成主动 `resume()`、500 ms 拿不到就静音播，CSS 里的 gate 是死样式。**以代码为准。**

观感（实看 `merge-shots/03-opening-film.png`）：构图与配色成立，像官方活动片而非自制；两个折扣是「外星字母」那行读起来像一排白块（易被误认字体缺失），以及静止帧偏空——动起来才补得回来。

### 3.2 皮肤的"决策层"：本次唯一改了 10-30 老结论的一条

10-30 的总纲把「皮肤呈现层」判成 **L 且不搬**。这次摸清：**那条同步链路我方早就有了，而且是自研的**——

```
pack.json.skins[i]  →  mergeWorkshopSkins  →  assets.skins[<charId>]  →  portraitChain 步骤 0「提供者先说话」
                                                                      →  room.appearance { picks, avatar }  ← 服务端存 + 全房广播
```

逐段核实：`shared/workshop.js:145/4225`、`public/js/ui/portraitChain.js:15/296`（开关 `settings.workshopSkins` 默认 true）、`shared/protocol.js:445-498/733`、`server/lobby.js:1249/2458-2496`。**缺的只有"谁在选"**：`settings.skinByChar` 只在一行注释里出现过、`skinPicker.js` 是 4 行 shim、没有任何外观提供者实现、客户端不读座位外观。

所以：**头像/立绘换装 = S**（做完玩家就能换，3–5 套手工皮肤即可验证链路）；**局内 Spine 换装 = M**（要动 `spineEntry` + `render/units.js` 缓存键；另有 34/598 个骨架的普攻 clip 不叫 `Attack*`，靠命名约定的渲染器会退化，要补一格映射）。

**素材**：302 款里 **276 款**落在我方已有干员上、**248 套**带得动局内模型；用不上的 26 套对应的干员我方还没有。体积 +344 MB（我方 `public/assets` 已 1.2 GB），正解是 `.spresources` 容器、不是散文件；官方美术入仓要先对 `NOTICE.md` 口径。

**纪律**：外观只走**一条**通道（建议工坊包）。两条通道（插件 overlay 的 `chars[charId].spine` 与工坊包 `art.spine`）同时写同一个干员必冲突。

### 3.3 桌面壳：只借「无窗口」这半个判断

先谈钱：它的壳净增量只有 **约 1.3 MB**（exe 169 KB + WebView2 SDK 936 KB + 启动页 24 KB），Node 运行时双方共用**同一份** `node.exe`（sha256 一致）。**体积不是决策变量。**

再谈它换来了什么：一个没有地址栏、没有黑窗口的窗口，加一张启动页（本地游戏 / 服务器地址 / 资源状态）。**它换来的是观感与入口，不是"能不能玩"** —— 后者（便携 node、就绪探测、地址打印、更新包、单实例、诊断）我方都比它完整。

它替我们标好的红线：

- 它自己的成品**在业主这台机器上就是崩的**：WebView2 Runtime 装着 156.0.4314.58，仍在 `EnsureCoreWebView2Async` 抛 `COMException 0x8000FFFF`；`async void` 裸 await 没人接，只写了日志，**也没有按文档承诺退回 `开始游戏.bat`**。这是「壳的失败面比 bat 大」的硬证据。
- 未签名 + `FileVersion 0.0.0.0` + `taskkill /T /F` + 起 `node.exe` 子进程 —— 这几样凑一起正是杀软启发式的经典特征，我方做壳会比它更容易被误报。
- 内嵌窗口会让玩家 `localStorage` 存档分叉（壳有私有 WebView2 profile）；我方存档全在浏览器里，**这是不可逆的**。
- 版本号被钉进 exe（`#US` 里只有一条 `version=0.3.3`），它发版就要重编译；我方发版频率更高。

所以建议：**先做 v0「无窗口 exe → 起 `scripts/launch.mjs --no-open` → 探 `/healthz` → 开系统默认浏览器 → 托盘退出」**，跑一个版本看有没有人抱怨"还有地址栏"，再决定 v1。v0 的全部技术难点我方都已具备（`launch.mjs` 的 `probePort`、`--port`、单实例、更新收尾），壳只负责"起进程 + 探活 + 退出"。

## §4 七个 S 级小件（可与主线并行，互不耦合）

1. **启动器日志**（`logs/launcher-YYYYMMDD.log`，时间戳 + 每次导航/探测/杀进程）—— 玩家报障时才有现场。
2. **失败出口人话化** —— `EADDRINUSE`、端口被占、node 缺失、素材未就绪，各给一句中文 + 下一步；现在 `boot.js:99` 还是英文。
3. **动图不被拍成静帧** —— 我方 `hubBackdrop.js:79-102` 把所有自选图过 canvas 重编码成 JPEG，GIF 变静帧、透明被填 `#0b1110`；借它 `isAnimatedImage()`（`lobbyMedia.js:97-118`，嗅探前 64 KB）一处分支即可。
4. **自选音乐时长上限** —— 我方只按 20 MB 卡（`lobbyMusic.js:8`），20 MB 能塞 40 分钟；加一条 `duration > 360s` 拒绝。
5. **自选图失效要说话** —— 我方图片走 CSS `background-image`，加载失败静默白屏；加一次 `<img>` 预探测 + toast + 回退。
6. **插件 CSP 声明合并** —— 只做「加白名单」（`BUILTIN_ALLOW` + `mergePluginCsp` 40 行），**永不做 `csp:"off"`**（见 §5.2），并且要进 schema 校验。

## §5 六条「别照抄」

### 5.1 别把「文档」当规格

### 5.2 两个"整站级"开关，别抄
- **`csp:"off"`**：融合版的 `mergePluginCsp` 支持插件把整站 CSP 关掉（只打一条 warning）。我方纪律是 `script-src 'self'` + import-map 哈希、**不放开 inline/eval**；这个开关必须砍掉，只保留「往白名单里加源」。
- **`/img-proxy`（SSRF 面）**：48 行，对任意 `http(s)` URL 发 `fetch`、`redirect:'follow'`、**不校验目标 IP**、还伪造 `User-Agent` 与 `Referer`（用于绕防盗链）。放在我方这种**公网自建服**上，等于给全网一个「用你的服务器打内网 / 云元数据地址」的接口。要接必须：解析并拒绝私网/回环/链路本地/云元数据地址（含每一跳重定向）、禁跟随到内网、域名白名单、限速。

### 5.3 「覆盖式安装器」永远最后考虑
两个整合包都带 `install.mjs`（标称引擎 0.2.x/0.3.1），会整文件覆盖核心文件。融合者自己的结论也写在 `MERGE-LOG.md:§6.1`：直接跑会删掉 0.3.3 的 versions / eventLoop / roomPool / llmGate。**只取 diff 里的钩子，落进当前版本的文件。**

### 5.4 CSP 的 `blob:` 有一处疑点（待一次实测）
融合版为「自选大厅视频/音乐」专门在 `server/http/csp.js:73` 放了 `media-src 'self' blob:` 并写注释说明原因；我方 `app/server/http/csp.js:48` 只有 `media-src 'self'${extra}`，而 `img-src` 那边我方早就写了 `blob:` —— 同一份策略里只有 media 这一半没有，而自选音乐/视频正是 `<audio src=blob:>` / `<video src=blob:>`。

### 5.5 三个启动入口要先收敛
