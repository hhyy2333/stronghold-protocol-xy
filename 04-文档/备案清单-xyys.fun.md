# xyys.fun ICP 备案清单（2026-10-18 起）

## 一、现状：Cloudflare 入口已撤

- 阿里云 47.122.107.213 上的 `cloudflared` 服务已 `disable --now`（开机不再自启）；
- CF 里 `xyys.fun` / `www.xyys.fun` 两条 CNAME 已删除（隧道 id `e5c2d272-e38f-4124-bcfa-2ec314516e88` 保留在账号里，随时可重开）；
- 现在 `https://xyys.fun` 不可用（530），玩家入口回到 `http://47.122.107.213`（实测 TTFB ≈ 50 ms，上海机器）；
- 撤掉的原因：CF 免费版把大陆流量绕到 **洛杉矶（LAX）**，TTFB 0.69–1.20 s，实时对局无法接受。

## 二、备案前置条件（逐项确认）

| 项 | 状态 |
|---|---|
| 阿里云账号已实名 | 需要（你已在用 ECS，基本已完成） |
| 域名 `xyys.fun` 已实名认证 | ✅ 已完成 |
| 域名在**同一个阿里云账号**下 | 需要确认（域名和 ECS 在不同账号不能一起备案） |
| ECS 支持申请「备案服务号」 | 需要确认：包年包月实例通常可申请；按量付费/剩余时长不足可能没有资格 |
| 网站负责人（个人：本人；企业：法人或授权人） | 需要准备 |

## 三、备案服务号（第一步，你来做）

阿里云控制台 → **备案** → **备案服务号申请** → 选这台 ECS → 申请。
一个备案服务号只能用于一个网站；服务号有有效期（约 30 天），别提前太久申请。

## 四、材料清单

**个人备案**：身份证正反面、本人手机号、邮箱、住址、紧急联系人；
**企业备案**：营业执照、法人身份证、网站负责人身份证、授权书（非法人时）。

网站信息：网站名称、首页地址（`xyys.fun`）、服务内容（见下）、语言（中文）。

## 五、⚠️ 网站内容怎么填（关键风险）

管局对「**游戏**」内容非常敏感：

- **个人备案**基本不能写游戏/游戏社区（个人网站不得从事经营性活动，游戏通常还要求文网文、版号）；
- 写「同人游戏」「游戏模拟」大概率被**阿里云初审打回**，或被管局抽查后要求整改/注销备案；
- 常见做法是写「个人技术项目 / 前端技术演示 / 个人学习作品」，但**内容与备案不符仍是风险**，是否这样填由你决定，风险自负。

**建议**：先想清楚这个站要长期公开给玩家，还是小范围。如果长期公开、且以后可能收钱/有商业化迹象，个人备案不合适，需要考虑企业主体。

## 六、时间线

1. 提交 → 阿里云初审（1–2 个工作日，会打电话核验）
2. 管局审核（官方 1–20 个工作日，通常 3–10 天）
3. 通过后拿到备案号（如 沪ICP备xxxxxxxx号-1），需要挂在页脚

## 七、备案通过后我要做的（10 分钟）

1. DNS：`xyys.fun` A 记录 → `47.122.107.213`（**灰云/直接解析**，不经 CF），或把 NS 迁回阿里云 DNS；
2. nginx 加 443 server 块 + Let's Encrypt 证书（HTTP-01 自动续期；也可走 DNS-01，CF 里建 TXT 即可）；
3. 80 → 443 301 跳转；
4. 安全组放开 443；
5. 验证：`https://xyys.fun` 的 `isSecureContext`、Service Worker、`/healthz`、WebSocket、`/assets|/fonts|/media` 缓存头、「导入素材包」可用；
6. 可选：备案通过后再挂**阿里云 DDoS 高防 / 全站加速（国内节点）**，同时拿到低延迟 + 抗 DDoS。CF 那条链路作为备用（需要时再开，但大陆延迟高，只当兜底）。

## 八、这期间玩家怎么办

- 继续用 `http://47.122.107.213`（快速、稳定）；
- 需要「导入素材包」的玩家暂时用不了（import 需要 https/localhost）；
- 预载素材照常可用（修复后的版本不再从 0 重数）。
