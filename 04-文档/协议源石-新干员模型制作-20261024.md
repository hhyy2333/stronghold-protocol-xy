# 自制干员模型：从 Spine 3.8.75 到游戏里能动的模型

> 适用版本：整合包 `app/` 0.19.x（引擎版本见 `shared/constants.js`）。
> 这篇讲「让新干员有一具**自己画的、会动的模型**」，不是「复用官方模型」，也不是「换立绘」。
> 只换立绘/头像看 `app/docs/task-01-换个立绘.md`；只想加数值先看 `app/docs/task-02-加个干员.md`。

---

## 0. 一条干员要过几道关

新干员就是一个**工坊包（workshop pack）**，引擎分层加载（`app/docs/WORKSHOP.md`）：

| 层 | 文件 | 负责什么 | 缺了会怎样 |
|---|---|---|---|
| 身份与数值 | `chess.json` | 商店能刷到、能上阵、普通/精锐两条记录 | 商店里没有她 |
| 外观素材 | `pack.json` 的 `art.chars` | 头像 / 立绘 / **战斗模型** | 画成一张菱形贴纸，**不报错** |
| 模型文件 | 包内 `assets/**` | `.skel` + `.atlas` + 贴图 `.png` | 同上，不报错 |
| 技能行为 | `kits/*.js`（可选） | 黑板书表达不了的效果 | 技能只有面板数字，没有机制 |

**模型这一层是本篇主题。** 引擎对模型的判据很窄，而且失败时**一律静默**——这是最容易踩的坑。

## 1. 引擎到底要什么（三条硬约束，写错全部静默）

依据：`app/shared/workshop.js` 的 `parseArtSpine`（约 1942–1990 行）、`app/public/js/assets.js` 的 `validSpine`（约 251 行）。

1. **格式必须是 Spine 3.8.x 的二进制 `.skel`**，不是 JSON 骨骼。
   校验器 `app/shared/workshopValidate.mjs:484-486` 只放行 `3.8.*`；运行时用 `@pixi-spine/runtime-3.8` 解析（`app/tools/assets/skel.mjs`）。
   3.8.75 导出的骨架版本串是 `3.8.75`，通过。
2. **`.atlas` 必须与 `.skel` 同目录、同文件名**（只换扩展名）。
   加载器是从 `.skel` 路径**推出** `.atlas` 的；`pack.json` 里那个 `atlas` 字段只用于内存回收。
3. **`.atlas` 里每一页 png 必须与它同目录同名**，且 `textures` 要把每页都列出来。

`spine` 对象允许的字段**只有**这几个（多写一个 `ART_UNKNOWN_FIELD`，少写 `skel`/`atlas` 就 `ART_SPINE_INCOMPLETE`）：

```json
{ "skel": "...", "atlas": "...", "textures": ["..."], "pma": false,
  "anims": { }, "animations": { }, "events": [], "hits": { }, "bounds": { } }
```

## 2. 在 Spine 3.8.75 里怎么画（美术侧硬指标）

引擎**不做任何自动适配**，模型多大就画多大：

| 指标 | 取值 | 依据 |
|---|---|---|
| 单位 | **320 骨架单位 = 1 格** | `app/public/js/render/style.js:207-209`（`UNIT.modelScale = 1/320`） |
| 原点 | **root 落在脚底**（脚踩 y=0），朝右为正向 | `app/public/js/render/units.js` 约 21–22、1576–1578 行：视角把 root 放地面点，朝左时整只水平镜像 |
| 身高 | 官方干员 `bounds.height` 中位数 **444**（≈1.39 格），p10 386（1.21 格），p90 781（2.44 格） | 由 `app/data/assets.json` 207 位有 bounds 的干员实测 |
| 朝向 | 站在 (0,0)、**脸朝右** | 同上，镜像只在渲染时做 |

> 画大了不报错，只是她比别的干员高一截。干员血条用统一 headroom，不吃 bounds；敌人吃（`units.js:277-282`）。
> 拿不准就把 setup pose 身高定在 380–500。

**贴图与图集**
- 图集用 Texture Packer 出 `.atlas` + 页 png；页名就是 png 文件名。
- `size: W,H` **必须存在**（pixi 要拿它做除法），缺了校验器报 `ART_ATLAS_NO_SIZE`。
- 预乘 alpha：要么图集写 `pma: true` 且 `pack.json` 也写 `"pma": true`，要么两边都不写；不一致报 `ART_PMA_HINT`。

## 3. 动画名：引擎按「角色」播放，不按动画名

`pack.json` 里的 `anims` 就是「角色 → 你的动画名」的映射。解析优先级写在 `app/tools/assets/anim-roles.mjs:18-38`。照着这张表做：

| 角色 | 建议动画名 | 何时播 |
|---|---|---|
| `idle` | `Idle` | 待机 |
| `deploy` | `Start` | 部署落场（**不是 born**，引擎只读 `roles.deploy`，`render/spine.js:798-807`） |
| `attack` | `Attack_Begin` / `Attack_Loop` / `Attack_End` | 攻击；单条也能写 `{"begin":null,"loop":"Attack","end":null}` |
| `attackDown` | `Attack_Down` | 目标在下方时（可省） |
| `skill` | `Skill_1_Begin` / `Skill_1_Loop` / `Skill_1_End` / `Skill_1_Idle` | 开技能；要 S2/S3 再补 `Skill_2_*`、`Skill_3_*` 并写进 `anims.skills` |
| `die` | `Die` | 阵亡（背面模型通常没有，退回正面模型的 Die） |
| `move` | `Move_Begin` / `Move_Loop` / `Move_End` | 移动（干员可省，敌人要用） |
| `stun` | `Stun` / `Stun_Begin` / `Stun_End` | 眩晕（没有就冻结当前动画，可接受） |

**最小可用集**：`Idle`、`Start`、`Attack`（或 `Attack_Loop`）、`Die`。少一个就会「能出来但不动 / 不消失」。

**背面不是必须的**：没写 `spine.back` 就一律用正面（`assets.js:191-195`）。要省工作量就只做正面。

---

## 4. OnAttack 事件：让打击点对得上

在 `Attack_Loop`（以及任何当攻击用的 Skill 循环）里，**在武器真正打中的那一帧插一个名为 `OnAttack` 的事件**，大约在片段 40%–60%。

引擎只读它的**时间**：
- `_hitTime` 取 `hits[动画名][0]`，拿不到就退回「片段中点」（`render/spine.js:742-746`）；
- 这个时间决定挥砍起手提前量与投射物出膛位置（`render/units.js` 的 boneOffset 一段）。

写进 `pack.json` 就是 `hits`：

```json
"events": ["OnAttack", "OnStart"],
"hits": { "Attack": [0.4], "Skill_1": [0.4] }
```

不做也**不报错**，只是打击点被当成正中，看起来「软」。

## 5. 导出（面板或命令行）

导出**两次**：骨架（二进制）+ 图集（Texture Packer）。

面板：`Export` 选 `Binary`（扩展名 `.skel`）；再用 Texture Packer 出 `.atlas` + `.png`，Max width/height 建议 1024，`Premultiply alpha` 要与 `pack.json` 的 `pma` 字段保持一致。

命令行（本机实测可用，Spine 安装目录 `examples/export/` 自带参数文件）：

```bat
"%SPINE_EXE%" -i my_op.spine    -o out\ -e binary.json
"%SPINE_EXE%" -i my_op\images   -o out\ -n my_op -p atlas-1.0.json
```

`binary.json` 只有三行：`{ "class": "binary", "extension": ".skel", "nonessential": "true" }`。

**`-n` 取的名字就是三个文件的公共文件名**，三者必须一致，图集页名也必须是它：

```
out/my_op.skel
out/my_op.atlas
out/my_op.png      <- .atlas 第一行也必须写 my_op.png
```

改过页名要同步改 `.atlas` 第一行，否则 `ART_ATLAS_PAGE_MISSING`。

## 7. 用脚本把 .skel 读成 anims

本篇附带一个只读小工具（它会自己找 `app/`）：

```bat
node 03-工具/spine-anims.mjs workshop/my-op/assets/art/char_ws_my_op/char_ws_my_op.skel
```

输出：骨架版本（非 3.8.x 直接报错退出）、**真实存在的**动画名与时长、事件名与每个动画的 `OnAttack` 命中时间、包围盒换算成「几格高」，以及一段可直接粘进 `pack.json` 的 `{ anims, animations, events, hits, bounds }`。

它用的是引擎同一个解析器（`@pixi-spine/runtime-3.8`），所以「校验器能读」与「游戏能读」是同一个判断。加 `--json` 只输出 JSON。

## 8. 静默失败对照表（先查这里）

| 游戏里的症状 | 真正的原因 | 校验器报的码 |
|---|---|---|
| 画成菱形贴纸 | `art.chars` 的 id 与 chess 的 `assetsSpine` 不一致 | `ART_UNKNOWN_ID`（warning，不挡） |
| 画成菱形贴纸 | `.atlas` 与 `.skel` 不同名/不同目录 | `ART_ATLAS_NAME_MISMATCH`（error） |
| 画成菱形贴纸 | `.atlas` 里的页 png 不在旁边 | `ART_ATLAS_PAGE_MISSING`（error） |
| 画成菱形贴纸 | 没写 `anims` | `ART_SPINE_NO_ANIMS`（新 id 上是 error） |
| 画成菱形贴纸 | `.skel` 不是 3.8.x / 读不出来 | `ART_SPINE_VERSION`（error） |
| 模型出来但一动不动 | `anims` 里的动画名在骨架里不存在 | `ART_ANIM_UNKNOWN`（error） |
| 模型出来但一动不动 | 覆盖官方 id 且没写 `anims` | `ART_SPINE_NO_ANIMS`（warning） |
| 比例不对 / 位置飘 | 没按 320 单位/格 画，或 root 不在脚底 | **不报错** |
| 颜色发灰/黑边 | `pma` 与图集不一致 | `ART_PMA_HINT`（warning） |
| 贴图错位 | `.atlas` 缺 `size:` 行 | `ART_ATLAS_NO_SIZE`（warning） |
| 以上都没有，但游戏里没变化 | 没重启游戏 | — |

完整校验码表见 `app/docs/WORKSHOP.md` §1.4 与 `app/docs/errors.md`。

## 9. 用 AI（spine-mcp-server）做模型：它能做哪一半

`spine-mcp-server` 把 **Spine 的命令行 `Spine.com`** 包成 MCP 工具（55 个 `spine_*`），让 Cursor / Claude Desktop 这类客户端用自然语言驱动编辑器动作。

**它能替你做**
- 体检工程：`spine_get_project_info`、`spine_list_animations`、`spine_list_constraints`、`spine_inspect_json`
- 搭骨架 / 挂部件：`spine_add_bone`、`spine_set_bone`、`spine_add_slot`、`spine_set_slot`、`spine_set_attachment`、`spine_add_attachment`
- 约束：`spine_add_ik` / `spine_set_ik`、`spine_add_transform` / `spine_set_transform`、`spine_add_path`
- 动画：`spine_add_simple_animation`（模板 idle/breath/walk/jump）、`spine_set_curve`、`spine_add_event_keyframe`、`spine_duplicate_animation`
- 出产物：`spine_export_animation`（**format: "binary"** 就是本篇要的 `.skel`）、`spine_repack_atlas`、`spine_split_atlas`、`spine_render_preview`（按帧渲 PNG）、`spine_export_video`

**它不能替你做**
- 画贴图 / 立绘本身；
- 演出设计（哪一帧好看、动作够不够脆）；
- **引擎侧的 `anims` 角色映射与 `hits`** —— 这是本项目自己的约定，不是 Spine 的；
- 把文件接进 `pack.json` 并跑校验（那一步用第 6 节）。

**本机怎么接**（2026-10-24 实测）

1. 装：任意**空目录**里 `npm install spine-mcp-server`（需 Node ≥ 20）。
   **别在 `app/` 里装** —— npm 会往上找到游戏的 `package.json` 并改写它。
2. 指路：它靠环境变量 `SPINE_EXE` 找命令行版编辑器，本机是
   `C:\Users\hhyyl\Downloads\Spine绿色学习版spine软件安装教程【鱼】\Spinepro_3.8.75学习版\Spine pro 3.8.75\Spine.com`
   （同目录的 `Spine.exe` 是图形界面，`Spine.com` 才是命令行）。
3. 客户端配置（Cursor 的 `.cursor/mcp.json` 或 Claude Desktop 的 `claude_desktop_config.json`）：

```json
{
  "mcpServers": {
    "spine-mcp": {
      "command": "node",
      "args": ["D:/tools/spine-mcp/node_modules/spine-mcp-server/dist/index.js", "mcp"],
      "env": { "SPINE_EXE": "<...>/Spine pro 3.8.75/Spine.com" }
    }
  }
}
```

4. 它**不打开 Spine 图形界面**，只 `spawn` `Spine.com`（单条命令 60 秒超时），改文件前自动备份 `.bak`（最多留 10 份）。
5. 局限：需 **Spine 3.8.75 专业版**授权（未激活时 CLI 直接失败）；3.8.55 只「尽力而为」；4.x 可能失败；只在本机用。

> 一句话：**AI 帮你「搭」和「改」，引擎认不认由第 1 节那三条硬约束决定，最后由 `workshop-validate.mjs` 说话。**

## 10. 全流程清单

- [ ] 320 单位 = 1 格；root 在脚底；脸朝右；idle 身高 380–500
- [ ] 动画：`Idle` / `Start` / `Attack`（或 `Attack_Begin+Loop+End`）/ `Die`；要技能加 `Skill_1_*`
- [ ] 在攻击动画里插 `OnAttack` 事件
- [ ] Export 选 **Binary**，`.skel` / `.atlas` / `.png` 三者同名
- [ ] Texture Packer 出 `.atlas` + `.png`，页名 = png 名，带 `size:`
- [ ] `node tools/workshop-scaffold.mjs <spec> --pack <id>` 生成 chess.json
- [ ] spec 里 `assetsSpine` = `art.chars` 的 id
- [ ] `pack.json` 补 `author` / `license` / `description`，别删 `content: ["chess"]`
- [ ] 用 `03-工具/spine-anims.mjs` 填 `anims` / `animations` / `events` / `hits` / `bounds`
- [ ] `node tools/workshop-validate.mjs workshop/<id>` → 0 error
- [ ] 重启游戏，商店里找她
