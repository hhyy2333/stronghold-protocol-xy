# 01 · 标题屏（Title）

> 文件：`app/public/js/screens/title.js`（298 行）+ `app/public/css/screens/title.css`（697 行）
> 平台：PC 横屏为主，手机横屏降级（高度 ≤660/560/520、竖屏 ≤1:1）

---

## 1. 页面目标与核心任务

| 项 | 结论 |
|---|---|
| 目标 | 3 秒内让玩家确认「这是什么游戏 + 服务器通不通」，然后**只做一件事：输入代号并开始** |
| 主任务 | 博士代号 → 开始（`enterSession`，`title.js:51`） |
| 次任务 | 统计 / 更新公告 / 语言 / 设置 / 全屏 / 玩法说明 / 素材下载与导入 / 续开对局 |
| 非目标 | 不放玩法数值、不放排行榜、不做账号登录（本作没有账号体系） |
| 首屏情绪 | 「战术终端开机」：暗场 + 雷达 + 目标点 + 霓虹薄荷线 |

## 3. 布局规范

| 区域 | 规则 |
|---|---|
| 整屏 | flex 居中；`align-items/justify-content:center`（`title.css:14`） |
| 节奏 | `--tg-1 .08rem / --tg-2 .16rem / --tg-3 .24rem`（8/16/24 设计px），**所有间距只能取这三个** |
| 品牌列宽 | 由内容撑开；`.title-login` 固定 `--console-w 5.6rem`（560 设计px），`max-width: calc(100vw - .48rem)` |
| 控制台内边距 | `.22rem .32rem .2rem`（`title.css:344`） |
| 四角皮标 | 距边 `.44rem / .38rem`（`:193-194`） |
| 底栏 | 贴底，三段式（左工具 / 中版权 / 右版本），`--tg` 间距 |
| 安全区 | 整屏已吃 `--sa-*`（`devices.css`），新元素不要自己再叠加 |

**垂直预算（1920×1080，按现有值估算）**：徽标 1.34rem + wordmark ~0.8rem + 标题 1.06rem + 副标 ~0.5rem
+ 控制台 ~3.3rem + 上下留白 ≈ 8.0rem，约占 1080 的 74%，余量足够加一层背景视差，**不够再加一行主按钮**。

## 4. 组件规格

### 4.1 徽标 `.emblem`
- 13×14 点阵，SVG `viewBox="-0.5 -0.5 14 15"`，画布 `1.18×1.27rem`（`title.css:250`）。
- 每点 `r = 0.2 + (行/13)*0.2`（下宽上窄），第 6/7 行第 5/7 列是 `is-accent`（`title.js:120-122`）。
- 两侧 `.emblem__bracket`：`.15rem × 1.52rem`、`2px` 边、只留一侧（`:260-262`）。
- 点阵动画 `dot-twinkle 4.8s` 逐点相位错开（`:251-257`）。

### 4.2 控制台 `.title-login`
- 底：`linear-gradient(180deg, rgba(10,24,22,.82), rgba(4,9,10,.94))` + 顶部薄荷径向光（`:345-348`）。
- 边：`1px var(--fx-line)`；四角括号：左上/右下薄荷、右上/左下更淡（`:373`）。
- 顶部「导流条」`::before`：斜切色块 + 向右渐隐的横线（`:360`）。
- 玻璃感：`backdrop-filter: blur(9px) saturate(1.2)`（`:355`）。
- 入场：`rise-in 600ms 260ms`（`:356`）——比品牌块晚 260ms，形成「先景后人」的节奏。

### 4.3 主按钮 `.btn--xl`
- 高 `.84rem`、字 `.28t`、`letter-spacing:.24em`、右下切角（`title.css:423`）。
- hover 时 `inset 0 0 0 1px #d9fff2` + 顶部内高光（`:431`）——**不要改成整块发光**，现方案是「硬件按键」质感。

### 4.4 状态点 `.status-dot`
- 三态：`is-on`（在线，呼吸）/ `is-warn`（连接中、重连中）/ `is-bad`（断开）（`title.js:193`）。
- 状态文案 7 种，全部走 `t()`（`title.js:159-162`）。

### 6.3 一致性自检（发现的偏差）

- 标题屏自带一套霓虹色：`--fx #35ffc4`、`--fx-ice #7ce7ff`（`title.css:22-25`），比全站
  `--mint-400 #59f4ca` / `--mint-glow #17f9b7` **更青更亮**。三屏放一起会看出色差。
  建议：保留标题屏的「开机感」，但把 `--fx` 改为 `var(--mint-glow)` 的近似值，或明确写注释
  「标题屏是霓虹特权，其它屏一律用 mint token」。**不要**在大厅/战绩里引入 `--fx`。
- 标题屏字号用 `--title-size 1.06rem` / `--tag-size .17rem`，而正文用 `calc(.18*var(--t))`；
  标题**没有**乘 `var(--t)`，所以「文字大小」设置对标题无效。这是有意还是遗漏需要业主确认
  （`title.css:29-32` 只列了 `--word-a/b`、`--title-size`、`--tag-size`，没有 `* var(--t)`）。

### 8.1 可访问性（现状 + 待补）

| 项 | 现状 | 待办 |
|---|---|---|

### 8.2 响应式（照现有断点补，不要加新断点）

| 断点 | 现状变化 |
|---|---|
| `max-height:660px` | 压缩品牌块与间距（`title.css:636`） |
| `max-height:560px` | 进一步压缩，控制台变窄（`:648`） |
| `max-height:560px and min-width:620px` | 横屏手机专用排布（`:664`） |
| `max-height:520px` | 最紧：徽标缩小、副标可能隐藏（`:673`） |
| `max-aspect-ratio:1/1` | 竖屏：改为纵向排布（`:687`） |
| 触屏 | 按钮实际像素 ≥ 32px |

## 10. 验收

1. `1920×1080`：底图无放大发虚感；主按钮、输入框、状态行三段对齐 `--tg` 网格。
2. `1280×720` / `1600×900`：品牌块不被裁切；控制台不超出 `calc(100vw - .48rem)`。
3. `844×390`（手机横屏）：`max-height:560px` 规则生效，副标不压按钮；触屏点按目标 ≥32px。
4. 断网：状态点 `is-bad` + 文案「连接已关闭」；「开始」仍可点（进大厅后再重连）。
5. 无素材包：不出现空白框，退回纯 CSS 雷达背景（`.title-bg` 无 `.has-art`）。
6. 减动效：所有视差/粒子/扫光静止，页面不闪。
7. 键盘：Tab 顺序 = 输入框 → 开始 → 预载素材 → 导入素材包 → 玩法说明 → 设置 → 全屏。
