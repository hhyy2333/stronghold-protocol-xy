## 验收命令

> 本机沙箱里 `node --test` 默认会为每个测试文件 spawn 子进程，而沙箱禁止带管道的子进程 → 必须加
> `--experimental-test-isolation=none`（在同进程跑）。**普通机器不加这个参数，直接 `node --test`。**

```powershell
cd C:\Users\hhyyl\Downloads\Stronghold-Protocol-v0.2.1\Stronghold-Protocol-Forge-协议源石版\app
$node = "..\node\node.exe"

# 1) 本次相关单测（沙箱写法）
& $node --test --experimental-test-isolation=none test/asset-paths.test.js test/ui/assetUrls.test.js test/ui/stats.test.js

# 2) i18n 五语言包齐全（改了文案必跑）
& $node tools/i18n.mjs check --all --strict

# 3) 素材清单体检（缺文件 / 大小写冲突 / 个人信息）
& $node tools/doctor.mjs

# 4) 全量 CI（普通机器；会跑 setup/test/smoke/lint/imports/typecheck）
npm run ci
```

**本次基线**（改动前后一致，可作为对照）：

- `test/asset-paths.test.js` → 2/2 通过
- `test/ui/assetUrls.test.js` + `test/ui/stats.test.js` → **44 通过 / 5 失败**
- `test/ui/stats.test.js` + `test/ui/difficulty-remember.test.js` → **44 通过 / 3 失败**
- `test/ui/{devices,matchmake,mods-ui,testArena}.test.js` → **33 通过 / 8 失败**
- 那 5 条是**既有失败**，与界面无关：`chess_char_6_21_a`（自制干员缺头像条目）、`band_admin2`（策略缺条目）
  等本机自制内容缺清单条目。**不要把它们的失败归到本次改动**。

> **`testArena` / `mods-ui` / `matchmake` 那 8 条也是既有失败**，原因已查明：
> 这些测试断言的是**上游那棵树**的实现 —— 例如它要求「测试场是一行 `.mode-strip` 紧凑条、且不在 `MODE_CARDS` 里」，
> 而本 Forge 树的 `lobby.js`/`lobby.css` 里 **`mode-strip` 出现 0 次**（测试场是 `MODE_CARDS` 里的普通入口卡）。
> 属于「测试没跟上这棵树的移植」，与本次改动无关。要修得单独开一轮，别混进界面改动。

## 风险清单

| 风险 | 说明 | 应对 |
|---|---|---|
| **`data/local-assets.json` 是生成文件** | 由 `tools/local-extract/extract.py` 生成；手工登记后**下次重跑 extract 会被覆盖** | 长期做法：把新组写进 `extract.py` 的 job 表（或新增 `tools/local-ui-extra.mjs` 并提交**脚本**）；短期：登记脚本提交进仓库，跑一次即可复现 |
| **`data/assets.json` 是生成文件** | 由 `tools/fetch-assets.mjs` 生成；手改会在下次 `npm run assets` 被覆盖 | 只通过工具改（本次就是这么做的：`tools/fetch-stats-assets.mjs`） |
| **大图体积** | `entry_bg[#1].png` 2.3 MB、`entry_anim_bg_02` 2.8 MB、`loading_ac_*` 各 ~0.9 MB | 落地前转 WebP（参考 `extract.py` 的 `WEBP` 步骤）；首屏图走 `<link rel=preload>` |
| **版权与分发** | 全部为 Hypergryph 素材，仅限非商用同人 | 不新增公开分发渠道；`07-素材包` 若要重打，按 `00-目录说明.md` §七 的既有流程 |
| **素材包重打** | 新素材若要让玩家导入，`07-素材包` 必须重打（否则校验不符） | 重打命令见 `00-目录说明.md` §七（`tools/package.mjs --assets --allow-dirty`） |
| **多语言溢出** | 英文模式名比中文长（`ALLIANCE SIMULATION`） | 入口卡 `white-space:nowrap` 要复核；必要时 `font-size` 用 `clamp()` |
| **手机横屏** | 新叠的卡面/横幅会压字 | 每个新增层都补 `@media (max-height:560px)` 降透明或隐藏 |
