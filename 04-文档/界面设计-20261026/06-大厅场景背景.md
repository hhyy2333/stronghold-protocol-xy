## 2. 素材是怎么拿到的（这次真的进了客户端 AB）

`UnityPy` 本来没装、pip 也装不上（写临时目录被沙箱拦 + 出网时通时不通）。这次处理：

1. `pip install UnityPy` 换成 `--timeout 120 --retries 5 --no-cache-dir` → **装上了**（UnityPy 1.25.4）。
2. 客户端 AB 是**自定义 LZ4AK 压缩**（Unity 记为 LZHAM），UnityPy 自带解压器不支持 →
   导入仓库里的 `tools/local-extract/aklz4.py`（它 import 时就把 `decompress_lz4ak` 注册进
   `CompressionHelper.DECOMPRESSION_MAP[LZHAM]`）→ 立刻能读。
3. 用新脚本 `tools/probe-home-bg.py` 列出 bundle 内对象并导出贴图。

`bg_rogue_3.ab` 的对象构成（实测）：

```
GameObject 26 · Transform 26 · Material 19 · ParticleSystem 15 · ParticleSystemRenderer 15
Texture2D 13 · MeshRenderer 9 · MeshFilter 9 · Sprite 3 · MonoBehaviour 3 · AssetBundle 1
```

导出的关键两张：`bg_rogue_3_left.png`（912×1024，RGBA）、`bg_rogue_3_right.png`（912×1024，RGBA）。

> **顺带确认**：第一张截图那个灰厅堂是 `bg_lonetrail_1`（孤星）；rogue_4 是灰白废墟、rogue_5 是界园
> （红山池塘）。**「始发」= `bg_rogue_3`** —— 雪原 + 冰湖 + 天环，与截图逐像素对得上。

## 3. 拼接（tools/home-theme-sheet.py）

官方把大厅按视口宽度切成左右两半，各 912×1024。`home-theme-sheet.py` 纯 paste 拼成 1824×1024：

```powershell
cd app
python tools/home-theme-sheet.py                    # 始发 → bg_start.png（默认）
python tools/home-theme-sheet.py --theme lonetrail  # 孤星 → bg_lonetrail.png
python tools/home-theme-sheet.py --check
```

> 星迹（`p3r_1`）已按业主要求删除，不再提供该 theme 选项；`THEMES` 表里只留 `start` / `lonetrail`。

**两个细节**（踩过）：
- 两半是 **RGBA**，边缘有透明。脚本先铺 `#050909`（与 `.lobby-hub` 同色）再 `alpha_composite`，
  否则透明边缘会透出白底。
- **不要做接缝羽化**：官方两半是严格相邻的像素，羽化会把地毯/雪面纹理糊出一条带。
  实测左右接缝无错位、无白线。
