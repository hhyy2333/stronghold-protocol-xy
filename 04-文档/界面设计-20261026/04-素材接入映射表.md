## 1. 三条通道与读法（先看这张）

| 通道 | 清单 | 读法 | 图在哪 | 随仓库走？ |
|---|---|---|---|---|
| ① 官方清单 | `app/data/assets.json` → `ui['组/名']` | `uiUrl(data.get('assets'), 'entry/bkg_01')` | `app/public/assets/ui/组/文件` | ✅ 是（下载式，`npm run assets`） |
| ② 本机提取 | `app/data/local-assets.json` → `groups['ui/outer'].<名>.path` | `localAsset('ui/outer','normal_rhodes_island')` | `app/public/assets/local/ui/outer/…` | ❌ 否（`public/assets/` 被 git 忽略） |
| ③ CSS/SVG | — | 直接写样式 | — | ✅ 是 |

**降级铁律**：① / ② 都可能返回 `null`（清单没登记、这台机器没提取）。此时：

- `<Img src=${url} fallback=${…}/>` —— `src` 为 `null` 时**直接渲染 fallback**，不会出破图（`app/public/js/ui/gameComponents.js:73`）；
- 背景图：`style=${url ? \`background-image:url("${url}")\` : ''}`，没有就保持 CSS 底色。

## 6. 怎么把新素材登记进「本机提取」组（不改 `data/assets.json`）

`data/assets.json` 是**随仓库走**的清单，`tools/setup.mjs` 会按它下载、`tools/doctor.mjs` 会按它查缺失、
`tools/package.mjs` 会按它打包。**往里塞 `/assets/local/…` 会三处全炸**（`tools/custom-assets.mjs:12-15` 有原话）。

正确做法（以标题屏的 `ui/entry` 组为例）：

```powershell
# 1) 建目录
$dst = "app\public\assets\local\ui\entry"
New-Item -ItemType Directory -Force $dst

# 2) 拷图（示例 3 张）
$src = "C:\Users\hhyyl\Downloads\其他解包文件：用户界面素材、交互界面切图等\其他解包文件：用户界面素材、交互界面切图等\其他解包文件更新9\活动 (activity)"
Copy-Item "$src\entry_bg[#1].png"  "$dst\entry_bg.png"
Copy-Item "$src\entry_bg_tree[#1].png" "$dst\entry_bg_tree.png"
Copy-Item "$src\entry_bg_bird[#1].png" "$dst\entry_bg_bird.png"
```

```js
// 3) 登记进 data/local-assets.json（一次性脚本，跑完就删；或写进 tools/local-extract 的 job 表里长期维护）
import fs from 'node:fs';
const P = 'app/data/local-assets.json';
const m = JSON.parse(fs.readFileSync(P, 'utf8'));
const g = (m.groups['ui/entry'] ||= {});
for (const [name, file] of [['entry_bg','entry_bg.png'], ['entry_bg_tree','entry_bg_tree.png'], ['entry_bg_bird','entry_bg_bird.png']]) {
  g[name] = { path: `/assets/local/ui/entry/${file}` };
}
m.count = Object.values(m.groups).reduce((n, x) => n + Object.keys(x).length, 0);
fs.writeFileSync(P, JSON.stringify(m));
console.log('ui/entry:', Object.keys(g).length, 'total:', m.count);
```

**注意**：
- `[#1]` 这类 Unity 后缀**必须去掉**再落地（文件名里的 `#` 在某些服务器/URL 编码下会出问题）。
- 同一张图在 `更新10/12/13` 里可能有多份副本，取**最新批次**，并核对文件大小一致（本次核对：同名副本内容一致）。
- 拷进 `public/assets/local/` 的图**不进 git**，别的机器没有 → 所以代码必须有降级。

## 7. 禁止事项（踩了会静默出事）

| 禁止 | 后果 |
|---|---|
| 把 `/assets/local/...` 写进 `data/assets.json` | `setup` 下载失败、`doctor` 报缺失、`package` 拒绝打包 |
| 手改 `data/assets.json` 而不跑工具 | 下次 `npm run assets` 被覆盖；`hash` / `stats` 与实际不符 |
| 用 `localAsset()` 却不写 fallback | 没有素材的机器上出现空白块 |
| 把可读文字画进图片 | i18n 五个语言包失效、屏幕阅读器读不到 |
| 新增动画不写 `prefers-reduced-motion` | 违反本工程既有无障碍约定 |
| 把 1024×460 的底图直接铺满 1920×1080 | 放大 1.9× 发虚（现状问题，见 [01-标题屏.md](01-标题屏.md) §6.1） |
| 在 `ui/outer` 里塞非自走棋的图 | 组名语义混乱；新图请另开组（`ui/entry`、`ui/stats` 等） |
