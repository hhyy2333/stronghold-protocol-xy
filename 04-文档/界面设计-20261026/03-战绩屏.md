# 03 · 战绩 / 统计屏（Stats）

> 文件：`app/public/js/screens/stats.js`（665 行）+ `app/public/css/screens/stats.css`（32.9 KB）
> 形态：**全屏浮层**（不是独立路由），`z-index:55`，可从标题 / 大厅 / 房间打开
> 关联：`public/js/screens/records.js` + `records.css`（对局战绩列表）

---

## 1. 页面目标与核心任务

| 项 | 结论 |
|---|---|
| 目标 | 让玩家看到「我打了多少、赢了多少、最远到哪、拿了哪些评语」——**回顾与炫耀**，不是做任务 |
| 主任务 | 5 个页签间快速切换，一屏内读完关键数字 |
| 次任务 | 导出 / 导入本机战绩（跨设备迁移）、清空、重看某局结算（`Replay`）、看排行榜 |
| 数据边界 | **纯本机数据**（`localStorage`），不上传服务器；页面顶部有明确告知（`stats.js` 的 `st-note`） |
| 首屏情绪 | 「作战档案室」：暗底 + 官方统计框 + 大字数字 |

## 3. 关键视觉件：评语六边形（TitleHexagon）

**这是本项目最特别的一件**，也是 `statistics/*` 缺键时损失最大的地方。

| 项 | 实现（`stats.js:273-310`） |
|---|---|
| 形状 | 6 个扇区（`TITLE_HEX_SECTORS`，每个带角度 `--sector-angle`） |
| 官方遮罩 | `statistics/titleMask`（`title-mask.svg`）→ 写成 CSS 变量 `--st-title-mask`；**只有图片真的 load 成功才加 `has-reference-mask` 类** |
| 光晕 | `statistics/countGlow`（`count-glow.png`）→ `--st-title-glow`，同样等 load 成功 |
| 扇区填充 | `titleSectorClip(count)` 生成 `clip-path`，`count` 越大扇区越大；`.is-bright` 在 `count ≥ 20` 时点亮 |
| 装饰 | `statistics/decoration`（`dash.png`），`.st-titlehex__decoration` |
| 降级 | mask 缺失 → 不加 `has-reference-mask` → 退回 CSS 多边形；glow 缺失 → 无光晕。**不报错、不留白框**（`Img` 组件 `src` 为 `null` 时直接返回 `fallback`，`gameComponents.js:73`） |

**结论**：这套「SVG 遮罩 + 扇区 clip-path」的写法是正确的，问题**只在于清单没登记那 37 个键**
（已在 [README §5](README.md) 修复）。修复后六边形才会真正呈现官方的六边形轮廓与计数光晕。

**新增元素必须沿用这个写法**。

## 7. 文案规范

| 位置 | 现状 | 规范 |
|---|---|---|
| 页签 | 总览 / 盟约&策略 / 战斗累计 / 对局记录 / 排行榜 | 2–5 字，名词，不带动词 |
| 微标签 | `STATISTICS // OVERVIEW` | 全大写英文，与页签一一对应 |
| 数字 | `fmtNum()` 千分位；空值 `—`（不是 `0`） | 空值永远 `—`，别用 0 假装有数据 |
| 统计口径 | 「计入统计：打到结算的对局，以及中途退出前至少清完 1 个回合的对局…」 | 必须保留，这是玩家最常质疑的地方 |
| 本机数据 | 「本机数据：只保存在这个浏览器里，不会上传到服务器…」 | 必须保留（隐私承诺） |
| 空态 | 「还没有记录 —— 完成一局对局后，这里会开始积累。」 | 建议补第二句 + 按钮（见 S2） |

## 10. 验收

1. 打开统计 → 总览：六边形有**官方轮廓**（修复前是 CSS 多边形）、标题条有官方底图、数字用官方数字字体。
2. 6 个稀有度框（`achievementTier1..6`）与 3 个精英角标（`elite0/1/2`）都能出图；删掉某张图 → 该项静默降级，**无破图**。
3. 空态：显示插画位 + 两个按钮，点「去大厅」能关掉浮层回到大厅。
4. 导出 → 得到 `stronghold-stats-YYYYMMDD-HHmm.json`；再导入 → 提示「已导入 n 条」或「全部重复」。
5. 清空 → 二次确认 → 列表变空态。
6. `stats.newer` 状态：正文替换为升级提示，导出/导入/清空全部禁用。
7. 手机横屏 `844×390`：页签可横向滑动；卡片两列；文字不小于 11px。
8. `prefers-reduced-motion`：无入场动画、无扇区生长。
9. 键盘：Tab 能到页签，左右键切页签，`Esc` 关闭。
10. 排行榜：不可用时给出明确说明而不是空白。
