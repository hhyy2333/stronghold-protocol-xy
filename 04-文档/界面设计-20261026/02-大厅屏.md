# 02 · 大厅屏（Lobby / Hub）

> 文件：`app/public/js/screens/lobby.js`（1379 行）+ `app/public/css/screens/lobby.css`（2537 行）
> 这是本作**最重要的一屏**：玩家 90% 的时间在这里做「选模式 → 选难度 → 开/加入同盟」。

---

## 1. 页面目标与核心任务

| 项 | 结论 |
|---|---|
| 目标 | 一屏之内回答三个问题：**跟谁玩（模式）→ 多难（难度）→ 现在有没有人** |
| 主任务 | 独立模拟 / 同盟模拟 / 无限火力 三选一 → 打开「选择模拟协议」浮层 → 创建或匹配 |
| 次任务 | 密钥加入、观战、招募房间列表、干员调配、协议源石禁用、扫荡报告、成就、好友、大厅背景、音乐 |
| 非目标 | 不在大厅里展示卡牌数值；不做商店 |
| 首屏情绪 | 「站在要塞观景台上」：远景山脊 + 雷达 + 中心徽标，功能卡贴底 |

## 3. 布局规范

| 区域 | 规则 | 不许做 |
|---|---|---|
| 三列 | 左 `2.6–3.2rem` 固定；中 `1fr`；右 `2.1*2+.14 = 4.34rem` 固定 | 不要改成百分比，会在大屏把中心挤空 |
| 行 | `minmax(0,1fr)` + `auto`：上行吃满、下行按入口卡高度 | 不要给 `.hub-stage` 加 `overflow:auto`（竖屏断点已单独处理） |
| 间距 | 列间 `.4rem`、行间 `.2rem` | 不要用 `--tg-*`（那是标题屏的节奏） |
| 入口卡行 | `align-items:flex-end`，右对齐（`lobby.css:948-951`） | 不要让入口卡撑满整行 |
| 手机横屏 | `max-height:560px and min-aspect-ratio:4/3`：招募卡只 2 行、plates 变矮（`lobby.css:1022`） | 不要隐藏入口卡 |
| 竖屏/窄 | `max-aspect-ratio:4/3`：单列 + 纵向滚动，顺序 center → entries → right → side（`lobby.css:1033`） | 不要让三列硬挤 |
| 触屏 | `.sp-touch/.sp-coarse`：入口卡 `max(1.7rem,112px)` 宽、`max(1.08rem,72px)` 高（`lobby.css:1044+`） | 不要低于 32px 实际像素 |

## 5. 视觉与素材方案（本节是重点）

### 5.1 素材存量（实测）

| 组 | 条数 | 代码引用 | 闲置 |
|---|---|---|---|
| `ui/outer` | 659 | **10** | **649** |
| `ui/battle` | 389 | 47 | 342 |
| `ui/common` | 160 | 6 | 154 |

大厅现在**没有一处**用 `localAsset('ui/outer', …)`（`grep localAsset` 在 `lobby.js` 里 0 命中）。
也就是说官方「模式选择 / 匹配 / 房间 / 玩家卡」整套图**全在盘上但一张没用**。

### 5.2 建议接入（按区块）

#### A. 模式入口卡 → 官方陆行舰剪影（**已落地，2026-10-26**）

**先说清一个坑**：官方这套 `*_rhodes_island` 是按**难度**上色的（normal 橙 / hard 红 / abyss 深红 / funny 黄），
而入口卡表达的是**模式**（独立 / 同盟 / 无限火力）。直接按「solo→normal、coop→hard」彩色铺上去，
玩家会读成「同盟 = 险境」，语义是错的。

**实际做法**：四张图取一张（`normal_rhodes_island`，427×332），**统一 `grayscale(1)` + 22% 透明度**当底纹，
颜色仍由卡自己的 `tone`（mint / gold）决定。这样它是「一张官方陆行舰的金属剪影」，不带难度暗示。

| 项 | 值 |
|---|---|
| 素材 | `ui/outer/normal_rhodes_island`（**已登记，无需新增**） |
| 位置 | 卡面右下角，`background-position: right bottom`，`background-size: auto 112%`（略微出血，靠 `overflow:hidden` 裁掉） |
| 遮罩 | `mask-image: linear-gradient(90deg, transparent 20%, #000 86%)` —— 只让右半出现 |
| 强度 | 常态 `opacity .22`；hover `:not(:disabled)` → `.34`；`--bright`（搜寻队友实心卡）→ `.12`；手机横屏 → `.16` / `.09` |
| 层级 | `.hub-entry__art` 是第一个定位子元素；`.hub-entry__en` / `__name` 加 `position:relative`，按 DOM 顺序后画 ⇒ 字一定在图上 |
| 降级 | `localAsset` 返回 `null` ⇒ **整层不渲染** ⇒ 回到原来的玻璃砖 |
| 减动效 | `@media (prefers-reduced-motion: reduce) { .hub-entry__art { transition: none } }` |

**还没做的**：把四张图**按难度**用在该用的地方 —— 难度卡。注意 `DifficultyCard`（`lobby.js:538`）是**死代码**，
真正渲染的是 `ProtoCard`（`lobby.js:645`，`.pcard` 样式），而它左侧已经有一幅原创难度图（`ui/protocolScene.js`）。
要不要把官方剪影叠进去，需要业主先看效果再定（见 §9 L4）。

| 入口 | 卡面主图（`ui/outer`） | 装饰 | 说明文字纹理 |
|---|---|---|---|
| 独立模拟 | `normal_rhodes_island.png`（207 KB） | `normal_thorn_left/right`、`normal_link_line_2/3`、`normal_cross` | `normal_desc_text.png` |
| 同盟模拟 | `hard_rhodes_island.png`（218 KB） | `hard_thorn_1..4`、`hard_link_line_2/3`、`hard_cross` | `hard_desc_text.png` |
| 无限火力 | `funny_rhodes_island.png`（189 KB） | `funny_link_line_2/3` | `funny_desc_text.png` |
| 测试场 | `normal_chess_01..03`（三张小棋片做叠影） | — | — |
| （预留）绝境/隐秘 | `abyss_rhodes_island.png`（208 KB） | `abyss_thorn_1..5`、`abyss_link_line_2/3`、`abyss_cross` | `abyss_desc_text.png` |

> 上表是**素材清单**（哪张图能干什么），不是「一对一映射建议」；实际映射见上面「先说清一个坑」。

**做法**：`.hub-entry` 加一层 `.hub-entry__art`，绝对定位铺满，`mask-image: linear-gradient(90deg, transparent 30%, #000 100%)`
让剪影只出现在右半边；`opacity .55`，hover → `.75`。文字仍在左下，不遮挡。
缺图时（`localAsset` 返回 `null`）整层不渲染 → 回到现在的玻璃砖，**不破坏降级**。

### 5.3 接入的技术约定

```js
// 1) 取图：本地提取组（模式棋片只在本机提取里，data/assets.json 没有这组键）
//    写法照 public/js/ui/components.js:188-192 的「先清单后本地」，只是这里反过来：先本地，没有就是 null
const modeArt = localAsset('ui/outer', 'normal_rhodes_island');

// 2) 渲染：没有图就整层不渲染（不要留空 <img>）
${modeArt ? html`<span class="hub-entry__art" style=${`background-image:url("${modeArt}")`} aria-hidden="true"></span>` : null}
```

```css
/* 3) 卡面层：只在右半边出现，不抢文字 */
.hub-entry__art {
  position: absolute; inset: 0; pointer-events: none; opacity: .55;
  background-position: right center; background-size: cover; background-repeat: no-repeat;
  -webkit-mask-image: linear-gradient(90deg, transparent 28%, #000 92%);
          mask-image: linear-gradient(90deg, transparent 28%, #000 92%);
  transition: opacity var(--t-med) var(--ease-out);
}
.hub-entry:hover:not(:disabled) .hub-entry__art { opacity: .78; }
@media (prefers-reduced-motion: reduce) { .hub-entry__art { transition: none; } }
@media (max-height: 560px) { .hub-entry__art { opacity: .35; } }   /* 矮屏别压字 */
```

**硬约束**：
- 图只做**背景层**，所有可读文字仍在 DOM 里（`<span>`），不能被图替代（i18n + 屏幕阅读器）。
- 每张图都要有 `aria-hidden="true"`。
- 不得把 `public/assets/local/**` 的路径写进 `data/assets.json`（那会随仓库走）。

## 6. 文案规范

| 位置 | 现状 | 规范 |
|---|---|---|
| 入口卡 | 独立模拟 / 同盟模拟 / 无限火力 / 测试场 / 搜寻队友 | 4 字优先；英文微标签全大写（SOLO / ALLIANCE / FIREPOWER / TEST FIELD / FIND ALLIES） |

| 难度名 | 标准 / 险境 / 绝境 / 终极（+ 隐秘核心标记） | 与官方一致，不改 |
| 匹配中 | 正在匹配同盟 (2/4)… + 计时 + 取消匹配 | 必须有**取消**；`n/m` 用 `num` 等宽字体 |

| 离线 | 只有 disabled | 建议 tooltip：「未连接服务器，暂时不能创建同盟」 |

新增文案同样要进 5 个 i18n 包。
